## Quillfeather - Reference of Keyboard Shortcuts

This document details the currently supported keyboard shortcuts for Quillfeather, a powerful and intuitive terminal-based text editor. These shortcuts are designed to maximize efficiency and streamline your workflow.  They utilize standard mnemonic keys where possible.

**I. Navigation (Movement & Jumping)**

These shortcuts move you around within the current file or buffer.

* **`Ctrl + f`**: Forward Character - Moves the cursor one character forward.
* **`Ctrl + b`**: Backward Character - Moves the cursor one character backward.
* **`Ctrl + a`**: Beginning of Line - Jumps to the very beginning of the current line. (Similar to 'Home' key)
* **`Ctrl + e`**: End of Line -  Jumps to the very end of the current line. (Similar to 'End' key)
* **`Alt + f`**: Forward Word - Moves the cursor one word forward.
* **`Alt + b`**: Backward Word - Moves the cursor one word backward.
* **`Ctrl + Left`**: Same as `Alt + b` (Backward Word).  Provides an alternative binding for users preferring it.
* **`Ctrl + Right`**: Same as `Alt + f` (Forward Word). Provides an alternative binding for users preferring it.
* **`Up Arrow`**: Move cursor up one line.
* **`Down Arrow`**: Move cursor down one line.
* **`Ctrl + Up Arrow`**: Scroll the view upwards (without changing cursor position).  This allows viewing lines above the visible screen.
* **`Ctrl + Down Arrow`**: Scroll the view downwards (without changing cursor position). This allows viewing lines below the visible screen.
* **`Ctrl + g`**: Go to Line Number - Prompts for a line number and moves the cursor to that location.  Enter `?` during prompt for help.

**II. Editing (Insertion, Deletion & Modification)**

These shortcuts allow you to modify the content of your file.

* **`Insert` / `Ctrl + o`**: Enter Insert Mode - Switches between insert mode (where characters are inserted) and replace mode (where existing characters are overwritten). The key used for insertion is configurable in Quillfeather’s settings.
* **`Delete`**: Delete Character - Removes the character to the right of the cursor.
* **`Backspace` / `Ctrl + h`**: Delete Backward Character - Removes the character to the left of the cursor.
* **`Ctrl + d`**: Delete Line (or EOF if at end) –  Deletes the current line or signals End-of-File if there are no more lines.
* **`Alt + d`**: Delete Word - Deletes the word after the cursor.
* **`Ctrl + w`**: Delete Backward Word -  Deletes the preceding word.
* **`Ctrl + k`**: Kill Line - Cuts (removes) the rest of the current line from the cursor position to the end, storing it in a temporary buffer for potential pasting.
* **`Ctrl + u`**: Ungrab Line - Removes text before the cursor up to the beginning of the line, saving to the kill buffer.
* **`Ctrl + y`**: Yank (Paste) – Pastes the last deleted or grabbed piece of content from the kill/ungrab buffer at the current cursor position.

**III. Search & Replace**

These shortcuts help in locating and modifying text within your file.

* **`/pattern`**: Forward Search - Searches for the given `pattern` forward through the document. Use `Enter` to accept, `Ctrl + c` to cancel.
* **`?pattern`**: Backward Search - Searches backward for the given pattern.  Use `Enter` to accept, `Ctrl + c` to cancel.
* **`:s/old/new/g`**: Substitute - Performs a search and replace globally (`g`) on the current line. Replace `:s` with other commands (see Quillfeather help).
* **`:%s/old/new/g`**: Substitute Globally (File) –  Performs the same substitution across the entire file.

**IV. Window Management & Other Actions**

These shortcuts manage windows, buffers and overall editor functionality.

* **`:q`**: Quit - Exits Quillfeather without saving changes.
* **`:wq` / `:x`**: Save and Quit – Saves the current buffer and exits Quillfeather.
* **`:w`**: Write (Save) -  Saves the current buffer to its associated file without exiting.
* **`:new`**: Open a New Buffer/Window - Opens a fresh, empty editing window.
* **`:buffer <number>`**: Switch Buffers – Allows you to navigate between existing buffers using their assigned numerical identifier.
* **`Ctrl + s`**: Save Current File -  Shortcut key for quickly saving the currently opened file (configurable).



This is a comprehensive list of shortcuts as of version [Current Version Number]. See the Quillfeather documentation (`:help`) within the editor itself for more details and advanced functionality.
