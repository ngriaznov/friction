## Getting Started with `dedupe-shots`: Finding & Removing Duplicate Photos

`dedupe-shots` is a powerful command-line tool that helps you reclaim valuable storage space by identifying and removing duplicate photos in your local photo library. It utilizes perceptual hashing (pHash) – a technique that generates unique fingerprints based on the visual content of images – allowing it to detect duplicates even if they’ve been resized, rotated, or slightly edited. This guide will walk you through installation, basic usage, and how to safely preview proposed matches before deleting.

**1. Installation**

`dedupe-shots` requires Python 3.6 or higher. You can install it using `pip`, the Python package installer:

```bash
python3 -m pip install dedupe-shots
```

This command installs the tool and its dependencies globally on your system.  You might need to use `sudo` before the command if you encounter permission errors (e.g., `sudo python3 -m pip install dedupe-shots`).

**2. Basic Usage: Scanning Your Photo Library**

The most fundamental operation is scanning a directory for duplicate images. Let's assume your photo library resides in `/path/to/your/photos`. Here’s how to initiate a basic scan:

```bash
dedupe-shots /path/to/your/photos
```

This command will start analyzing the contents of the specified directory.  The process involves calculating a pHash for each image, comparing these hashes, and identifying clusters of potentially duplicate images. `dedupe-shots` displays progress information on your terminal during this analysis.

By default, `dedupe-shots` uses a similarity threshold (Hamming distance) to determine if two images are considered duplicates.  A lower Hamming distance means more similar. The default value is usually adequate for most scenarios.

**3. Understanding the Output & Similarity Scores**

After completing the scan, `dedupe-shots` will display groupings of potential duplicate images along with their similarity scores (Hamming distances). For example:

```
Group 1:
  /path/to/your/photos/image001.jpg   (Hash: aabbccddeeff)    Similarity: 3
  /path/to/your/photos/resized_image001.png (Hash: aabbccddeeefg) Similarity: 2
  /path/to/your/photos/rotated_image001.jpeg  (Hash: aabbccddeeeffh) Similarity: 4

Group 2:
  ... and so on
```

* **`Group [Number]`:** Each number represents a distinct group of potentially duplicate images.
* **`/path/to...`:** The full path to each detected image file.
* **`(Hash: ...)`:** A shortened representation of the perceptual hash for that image (for debugging).
* **`Similarity: `:**  The Hamming distance between the two candidate duplicates. Lower is *more* similar.

**4. Previewing Matches Before Deletion – The Safe Approach!**

Deleting photos without confirmation can be disastrous. That's why `dedupe-shots` strongly encourages using the `--preview` flag before taking any irreversible actions.

To preview matches, run:

```bash
dedupe-shots /path/to/your/photos --preview
```

This command performs a full scan as above, but instead of deleting duplicates, it presents you with interactive previews.  You'll be prompted to confirm each proposed deletion on a pair-by-pair basis. This allows for human judgement in cases where the automatic detection might be incorrect (e.g., two very similar sunset photos that are actually distinct).

**5. Removing Duplicate Photos (With Caution!)**

Once you’re confident with the identified duplicates, and *only* after thorough previewing, you can proceed to remove them using the `--delete` flag:

```bash
dedupe-shots /path/to/your/photos --delete
```

**IMPORTANT:**  The `--delete` flag permanently removes duplicate photos. It is highly recommended that you **back up your photo library before running this command**. `dedupe-shots` does *not* provide an undo function!

**Advanced Usage and Configuration:**

* **Adjusting Similarity Threshold:** Use the `--threshold` option to modify the sensitivity of duplicate detection (e.g., `--threshold 5`).
* **Ignoring Specific Files/Directories:**  The `--exclude` option allows you to exclude certain files or directories from the scan.
* **Detailed Logging:** The `--log-file` option enables logging detailed information about the scanning and deletion process for troubleshooting.
