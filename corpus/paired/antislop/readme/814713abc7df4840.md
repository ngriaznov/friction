# phodedupe - Find Duplicate Photos with Confidence

phodedupe is a command-line tool written in Python that identifies duplicate photos within one or more directories. It utilizes perceptual hashing (pHash) to reliably detect duplicates even when they've been resized, cropped, slightly recompressed, or otherwise modified – problems that traditional checksum comparisons fail at.  This drastically improves accuracy compared to simple file size/hash checks.

**Why Use Perceptual Hashing?**

Traditional duplicate detection often relies on comparing MD5, SHA-256, or other cryptographic hashes. These are perfect detectors: a different hash *always* means a different file. However, even minor changes (a slight compression adjustment, resizing to 1920x1080) dramatically alter the checksum while leaving the image largely visually identical.

pHash generates a signature representing the *visual content* of an image. Similar images will have similar signatures, allowing phodedupe to identify them as likely duplicates even with these modifications. This makes it far more effective at finding true duplicates in practical scenarios like messy photo libraries.

**Installation**

Install using pip:

```bash
pip install phodedupe
```

**Basic Usage**

To scan a directory for duplicate photos and generate a report, use the following command:

```bash
phodedupe /path/to/your/photo/directory
```

This will:

1. **Scan:** Recursively traverse `/path/to/your/photo/directory` (and its subdirectories) to identify images.
2. **Hash:** Generate a perceptual hash for each image using the default algorithm (explained in Configuration).
3. **Group:** Group images based on their similarity, determined by comparing their hashes against a configurable threshold.
4. **Report:** Print a report displaying groups of potentially duplicate photos.  Each group will contain paths to files with similar visual content.

**Reviewing and Deleting (Safety First!)**

*Crucially*, phodedupe **does not automatically delete anything.** The purpose of the initial run is for *review*. Examine each identified duplicate group carefully before deleting any images!

Once you are confident about which photos should be removed,  you can use the `-d` or `--delete` flag.  **Use this with extreme caution and always back up your data first!**

```bash
phodedupe -d /path/to/your/photo/directory
```

This will delete all but one image from each identified duplicate group (the "first" encountered).

**Dry-Run Mode**

To preview the changes without actually deleting anything, use the `--dry-run` flag:

```bash
phodedupe --dry-run /path/to/your/photo/directory
```

This will execute all steps of duplicate detection and reporting *without* removing any files.  Perfect for testing!

**Configuration Options**

You can customize phodedupe’s behavior using the following options:

* `--algorithm <algorithm>`: Specify the perceptual hashing algorithm to use. Available algorithms include `average` (the default), `difference`, `db`. Different algorithms can offer varying performance and robustness.
* `--threshold <float>`:  Adjust the similarity threshold for identifying duplicates. The higher this value, the more similar two images must be to be considered a duplicate. A lower value will identify more potential matches but could also yield false positives. (Default is 0.1)
* `--min-size <int>`: Minimum image size in bytes that triggers processing.  Useful to skip very small thumbnails or corrupted files.
* `-h` or `--help`: Display this help message and exit.

**Example with Options:**

```bash
phodedupe --algorithm difference --threshold 0.05 /path/to/your/photo/directory
```

This command uses the 'difference' algorithm, a lower similarity threshold (more aggressive duplicate detection), and specifies the path to scan.
