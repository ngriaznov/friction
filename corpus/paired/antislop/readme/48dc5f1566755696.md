# csvtype: Typed CSV Parsing in Rust

`csvtype` is a powerful and ergonomic Rust crate that simplifies working with CSV files. It automatically infers the data types of columns (integer, float, date, boolean, string) by sampling rows from your file. Instead of dealing directly with strings, `csvtype` provides you with an iterator that yields records comprised of typed fields – dramatically reducing parsing overhead and improving type safety.

## Features

* **Automatic Schema Inference:** Detects data types within CSV columns using a configurable number of sampled rows.
* **Typed Records:** Provides an iterator yielding records where each column is parsed to its detected type (e.g., `i32`, `f64`, `bool`, `Date`, `String`).
* **Customizable Sampling:** Control the accuracy and performance of schema inference by adjusting the number of rows sampled.
* **Column Type Overrides:** Allows for manual overrides if automatic detection fails or is inaccurate, ensuring that your program processes data correctly.
* **Flexible Date Parsing:**  Supports various date formats (see `Date` type in documentation) with customization options.
* **Error Handling:** Comprehensive error handling to gracefully manage parsing and inference failures.

**Note:** `csvtype` depends on `openssl` for the date parsing functionality. The above snippet includes a conditional dependency to install it only if building on Unix systems. If you're encountering linking issues, ensure your system has `libssl-dev` installed and that the optional feature is enabled in your dependencies.

## Basic Example

```rust
use csvtype::{CsvReaderBuilder, Date};
use chrono::NaiveDate;

#[derive(Debug)]
struct Record {
    id: i32,
    name: String,
    amount: f64,
    is_active: bool,
    created_at: Date<NaiveDate>, // Use the `Date` type from csvtype for dates.
}

fn main() -> Result<(), Box<dyn std::error::Error>> {
    let path = "data.csv"; // Replace with your file's path

    // Create a CsvReaderBuilder and infer the schema using 10 rows of sampling.
    let mut reader_builder = CsvReaderBuilder::new(path)
        .has_header(true)
        .infer_schema(10);

    // Configure custom date parsing if needed:
    // .date_format("%Y-%m-%d") //Example - change to your required format

    let reader = reader_builder.from_reader();

    for result in reader {
        let record = result?;
        println!("{:?}", record);
    }

    Ok(())
}
```

**`data.csv` (example):**

```csv
id,name,amount,is_active,created_at

2,Bob,67.89,false,2023-10-27
3,Charlie,90.12,true,2023-10-28
```

## Considerations and Configuration

* **Sampling Size:** The `infer_schema()` method takes an integer argument that specifies the number of rows to sample for automatic type detection. A larger sampling size generally leads to a more accurate inference but increases parsing time during schema discovery. Start with a reasonable value (e.g., 10-50) and adjust as needed based on your data's complexity.
* **Data Heterogeneity:**  If columns contain mixed types, the inferred type might be the most common one encountered in the sample. Carefully review automatically determined types for unexpected behavior.
* **Column Type Overrides:** When automatic detection fails or is incorrect, you can manually specify column types using the `set_column_type()` method on the `CsvReaderBuilder`.  For example:

    ```rust
    let mut reader_builder = CsvReaderBuilder::new(path)
        .has_header(true)
        .infer_schema(10)
        .set_column_type("amount", csvtype::ColumnType::Float); // Force the 'amount' column to be a float

    ```

* **Date Parsing:** The `Date` type offers multiple constructors and parsing methods, allowing for flexible date handling.  You can customize the expected date format using `.date_format()` during builder configuration.
* **Error Handling:** Always handle errors gracefully when reading from CSV files. Use pattern matching on the `Result` returned by the iterator to manage potential issues like incorrect number of columns or parsing failures.
