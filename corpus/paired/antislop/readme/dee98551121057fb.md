# Packlite: Lightweight Bundler for Simple Static Sites

Packlite is a Node.js command-line tool designed to efficiently bundle and minify your JavaScript and CSS assets into optimized files ready for deployment on simple static websites. Unlike heavier, feature-rich build tools often used with SPA frameworks (like Webpack or Parcel), Packlite focuses on the essentials - getting your core code bundled quickly without unnecessary overhead.

**Who is this for?**

* Developers creating personal blogs, landing pages, documentation sites, or other relatively straightforward static websites.
* Projects where you want tight control over bundle size and build times.
* Those seeking a simpler bundling experience than full-fledged framework tooling provides.

## Installation

Packlite requires Node.js v16 or higher.  Install globally using npm:

```bash
npm install -g packlite
```

You can verify the installation with:

```bash
packlite --version
```

## Configuration

Packlite relies on a configuration file (`packlite.config.json`) to define your project's entry points and output paths.  Here’s an example:

```json
{
  "entryPoints": {
    "app.js": ["./src/scripts/main.js", "./src/scripts/utils.js"], // Concatenate multiple JS files into app.js
    "style.css": "./src/styles/global.scss",                       // Compile and bundle a single CSS file
    "vendor.js": ["https://example.com/external-library.min.js"]  // Include external URLs directly (no bundling)
  },
  "outputDirectory": "dist",
  "minify": true,
  "generateSourceMaps": false // Consider enabling for debugging in development
}
```

**Explanation:**

* **`entryPoints`**: This is the core of your configuration. Each key represents the *name* of the generated output file (e.g., `app.js`). The corresponding value is either:
    * A string, representing a single entry point to bundle (like `./src/styles/global.scss`).
    * An array of strings, where each element is a path to another script or stylesheet that will be concatenated into the final bundled file (like `["./src/scripts/main.js", "./src/scripts/utils.js"]`).  URLs can also be included; these are copied directly without bundling and listed in the output comment of the bundled javascript.
* **`outputDirectory`**: Specifies where Packlite will place the generated files. Defaults to "dist".
* **`minify`**: A boolean that enables or disables minification (defaults to `true`).
* **`generateSourceMaps`**: Enables generation of `.map` source map files for debugging (defaults to `false`).

## Usage

Once configured, bundling is simple:

```bash
packlite
```

This will process your configuration and generate the bundled and minimized files in the specified output directory.

## Watch Mode (Development)

For rapid development, use watch mode:

```bash
packlite --watch
```

Packlite will now monitor changes to your project’s source files. Whenever a change is detected, it automatically rebuilds the corresponding bundles.

## Source Maps

During development or troubleshooting in production, enabling source maps can significantly aid debugging:

1. **Enable generation:** Add `"generateSourceMaps": true` to your `packlite.config.json`.
2. **Serve with appropriate headers:** When serving the bundled files (e.g., from your web server), ensure you include the correct HTTP headers for browser source map support.

## Performance Comparison

Compared to using heavier, more comprehensive build tools like Webpack on smaller projects, Packlite often demonstrates a significant performance advantage:

| Scenario                 | Webpack (Typical) | Packlite    | Reason                                       |
|--------------------------|--------------------|-------------|-----------------------------------------------|
| Initial Build Time     | 10-30 seconds      | 1-5 seconds | Simplified process, minimal dependencies       |
| Incremental Build Time  | 5-20 seconds      | <1 second    | Selective rebundling only changed files        |
| Bundle Size Overhead   | Several MB         | Minimal     | Smaller tool footprint                         |

The difference is most noticeable on simple projects. However, Packlite may lack the more advanced features of larger tools (code splitting, hot module replacement, sophisticated loaders).  Consider your project's needs when choosing a bundling solution.
