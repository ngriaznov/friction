# tasq - Plain Text Todo Manager

tasq is a simple command-line todo manager that prioritizes readability and version control friendliness. Instead of storing your tasks in a database or proprietary format, it saves them as plain text lines within a designated file. This makes your task list easily readable directly in a text editor and integrates seamlessly with version control systems like Git.

## Installation

Just copy the `tasq` executable to somewhere in your `$PATH`. For example:

```bash
cp tasq /usr/local/bin
```

You might need root privileges (using `sudo`) to install it this way.  Alternatively, check if you can just move the binary where the system finds executables.

## Usage & Syntax

Here's how you use tasq:

**1. Adding Tasks:**

Simply provide a description for your task as an argument:

```bash
tasq "Buy groceries"
tasq "Finish report - due Friday @work"
```

*   Tasks are automatically assigned a unique ID (starting from 1) and added to the task list.
*   **Tags:** Add tags using the `@` prefix.  This allows for filtering later. For example, `“Schedule meeting @planning”`.
*   **Due Dates:** Indicate due dates directly in the description. tasq parses common date formats (YYYY-MM-DD, MM/DD/YY etc.).

**2. Completing Tasks:**

To complete a task, provide its ID to the command:

```bash
tasq -c 3  # Marks task #3 as completed
```

Completed tasks are marked with `[x]` at the beginning of their description.

**3. Listing Tasks:**

Without arguments, `tasq` lists all incomplete tasks in order of creation:

```bash
tasq
```

**4. Filtering Tasks:**

*   **By Tag:** Use the `-t` or `--tag` option to list only tasks with a specific tag:

    ```bash
    tasq -t work  # List only tasks tagged with "work"
    ```

*   **By Due Date:**  Use the `-d` or `--due` option followed by a date string in `YYYY-MM-DD` format to filter for tasks due on that specific date:

    ```bash
    tasq -d 2024-12-31 # List only tasks with a due date of December 31, 2024
    ```

## Configuration & The Task File

By default, tasq stores your task list in `~/.tasks`. You can change this location by setting the `TASQ_FILE` environment variable:

```bash
export TASQ_FILE=/path/to/your/custom/taskfile.txt
tasq # Now uses /path/to/your/custom/taskfile.txt
```

This allows you to easily keep your task list synchronized between different environments or integrate it with other tools.  Because it's a plain text file, using `git diff` can show changes to the whole todo list - excellent for tracking progress and reverting mistakes.
