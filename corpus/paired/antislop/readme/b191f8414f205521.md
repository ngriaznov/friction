# Lumen - Photography Portfolio Generator

[![License](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)
[![Gem Version](https://badge.rubyversions.org/lumen.svg)]()

Lumen is a lightweight, static site generator tailored for showcasing photography portfolios. It's built as a Ruby gem and offers automatic thumbnail creation, EXIF-based caption extraction, and a streamlined workflow designed to be intuitive even without extensive coding experience.  The generated output (HTML, CSS, JavaScript) can then easily be deployed to any web hosting provider or CDN.

## Installation

Add Lumen to your project:

```bash
gem install lumen
```

## Usage & Folder Convention

Lumen expects a specific folder structure for optimal results. This allows it to automatically organize and process your images and content. Here's the recommended layout:

* **`_pages/`**:  This directory holds your markdown-based pages (e.g., "about.md", "contact.md").
    *  Each `.md` file in this folder becomes a separate page on your portfolio site. No front matter is needed – Lumen assumes content within these files are the main body of the page.
* **`_galleries/`**: This directory contains folders, each representing a photo gallery.
    * **Gallery Folder Example:** `_galleries/landscape-photography/`
        *  Inside this folder, you place all your image files (e.g., "image1.jpg", "image2.png"). The order of these files determines their display sequence in the gallery.
        * No additional files are needed within a gallery directory – Lumen automatically processes all supported image formats.

**Supported Image Formats:** JPG, JPEG, PNG, GIF (further expansion possible with future releases).

**Example Directory Structure:**

```
my-portfolio/
├── _pages/
│   └── about.md
│   └── contact.md
├── _galleries/
│   ├── landscape-photography/
│   │   ├── image1.jpg
│   │   ├── image2.png
│   │   └── ... more images
│   ├── portraiture/
│   │   ├── picture_a.jpeg
│   │   └── ... more portraits
│   └── travel-series/
│       └── ...
├── lumen.yml  # Configuration file (explained below)
└── README.md
```

## Build Process

To generate your portfolio website, simply run the following command from your project's root directory:

```bash
lumen build
```

This will process all `.md` files in `_pages/` and image folders within `_galleries/`, creating a fully functional HTML site in the `public/` directory (by default).  You can then upload this entire `public/` directory to your web server.

## Local Preview Server

For easier development, Lumen provides a built-in preview server:

```bash
lumen serve
```

This command starts a local web server (typically on port 3000) allowing you to see changes immediately as you edit files.  Navigate to `http://localhost:3000` in your browser to view the live portfolio during development. The server automatically detects file changes and refreshes the display.

## Automatic Thumbnail Generation & EXIF Caption Extraction

* **Thumbnails:** Lumen automatically generates thumbnails for each image within a gallery. These are used for displaying previews on gallery overview pages. Thumbnails are stored in `public/thumbnails/`.
* **Captions (EXIF):**  By default, Lumen attempts to extract the "Caption" or "Image Description" field from the EXIF metadata of your images and use it as a caption displayed below each image within a gallery. If this field is missing, no caption will be shown.

## Configuration (`lumen.yml`)

The `lumen.yml` file provides centralized control over several aspects of your portfolio's appearance and behavior. This single YAML file handles the global settings for your site.  If one doesn’t exist in your project root directory, running `lumen build` will automatically generate a basic example. Here’s an explanation of its sections:

```yaml
# Required configuration
title: My Awesome Photography Portfolio   # The title that appears in the browser tab and header.

theme: simple                       # Choose from available themes (see Themes section).  'simple' is the default.

# Optional, but highly recommended
output_directory: public             # Directory where your generated website files will be placed. Default is 'public'.

# Thumbnail Configuration (advanced) - typically no need to change
thumbnail_size: 400                  # Width of generated thumbnails in pixels.  Height is calculated automatically to maintain aspect ratio.

# EXIF Caption Handling (advanced) – only adjust if needed
exif_caption_field: ImageDescription   # The specific EXIF tag Lumen should use for captions.  'Caption' can also be used.

```

**Themes:** Currently, `lumen` supports the `simple` theme. Future releases will offer more themes to customize your portfolio’s overall look and feel without modifying any code directly.
