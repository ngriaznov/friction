# tasq - Plain Text Todo Manager

tasq is a simple command-line todo manager that stores your tasks as plain text lines in a file, making them easily readable and diffable using version control systems like Git. Forget complex database setups – keep your to-dos right alongside your code!

## Installation

Simply clone this repository or copy the `tasq` script (typically a Bash or Python script) into a directory on your system’s PATH.  Make sure the script is executable (`chmod +x tasq`).

## Usage

The core command is `tasq`. Here's how to use it:

**1. Adding Tasks:**

   To add a new task, use the `add` subcommand followed by the task description:

   ```bash
   tasq add "Grocery shopping"
   tasq add "Write documentation for tasq" @documentation
   tasq add "Pay bills" 2024-03-15
   tasq add "Review code changes" @code @urgent 2024-03-12
   ```

   * Tasks are added to the end of the task file.
   * **Tags:** You can assign tags using the `@` prefix (e.g., `@documentation`, `@urgent`).  These tags allow you to filter your tasks later.
   * **Due Dates:** Due dates are specified in `YYYY-MM-DD` format (e.g., `2024-03-15`). Tasks with due dates will be sorted chronologically when listing.  You can include both tags and due dates on the same task line.

**2. Completing Tasks:**

   To mark a task as complete, use the `complete` subcommand followed by the *line number* of the task in the task file:

   ```bash
   tasq complete 3  # Marks the third task as completed
   ```

   Completed tasks are marked with `[x]` at the beginning of the line.

**3. Listing Tasks:**

   To view your current to-do list, simply run:

   ```bash
   tasq
   ```

   This will display all active (incomplete) tasks, sorted by due date and then insertion order for tasks without a due date.  Completed tasks are shown at the end of the list, marked as complete.

**4. Filtering Tasks:**

   * **By Tag:** Use the `--tag` option to filter tasks based on a specific tag:
     ```bash
     tasq --tag documentation # Shows only tasks with the @documentation tag
     ```

   * **By Due Date:**  Use `--due` to show tasks due on a specific date.
     ```bash
     tasq --due 2024-03-15 # Show tasks due on March 15, 2024
     ```
     You can combine filters: `tasq --tag urgent --due 2024-03-12`

## Configuration & Task File Location

By default, tasq stores tasks in `~/.tasq.txt`. You can change this location by setting the `TASQ_FILE` environment variable before running tasq:

```bash
export TASQ_FILE=/path/to/your/tasks.txt
tasq add "New task"
```

This allows you to store your tasks in a custom location, potentially within your project's repository for easy tracking alongside other files.
