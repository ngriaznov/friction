# Lumen - Photography Portfolio Static Site Generator

[![Gem Version](https://badge.rubyforge.org/shields/version-gem/lumen)](https://rubygems.org/gems/lumen)
[![License](https://img.shields.io/badge/license-MIT-blue.svg)](https://github.com/your-username/lumen/blob/main/LICENSE)

Lumen is a Ruby gem designed specifically for creating beautiful and efficient static photography portfolios. It prioritizes ease of use, automated thumbnail generation, and intelligent caption extraction from your images using EXIF data.  No more wrestling with complex templating engines – Lumen lets you focus on your photography!

## Features

* **Simple Folder Structure:** Intuitive organization for galleries and pages.
* **Markdown Support:** Write content in plain Markdown.
* **Automated Thumbnail Generation:** Automatically creates thumbnails for all images within a gallery.
* **EXIF-Based Captions:** Extracts captions directly from the EXIF data of your photos.  No manual captioning needed! (Requires image files with properly populated `ImageDescription` EXIF tags).
* **YAML Configuration:** Centralized configuration for site title, theme, and output directory.
* **Local Preview Server:** Quickly preview changes before deployment.
* **Themeable:** Easily customize the look and feel of your portfolio by swapping themes (theme support coming soon - see "Future Enhancements").

## Installation

Add Lumen to your Ruby project:

```bash
gem install lumen
```

## Folder Convention & Content Structure

Lumen relies on a specific folder structure for optimal functionality.  Here's how you should organize your content:

* **`_pages/`:** Contains Markdown files representing individual pages (e.g., "about.md", "contact.md"). These files *should not* have front matter (YAML headers). Lumen will use the filename as the page title.
* **`_galleries/`:**  This is where your photo galleries reside. Each gallery should be a directory named after its intended display name (e.g., `_galleries/paris-trip/`).
    * Inside each gallery directory, place all images for that gallery. The image filenames will determine the order they are displayed. Lumen supports common image formats like JPG, JPEG, PNG, and GIF.

**Example:**

```
my-portfolio/
├── _pages/
│   └── about.md
│   └── contact.md
├── _galleries/
│   └── paris-trip/
│       ├── photo1.jpg
│       ├── photo2.png
│       └── photo3.jpeg
└── lumen.yml  # Configuration file (explained below)
```

**Important:** The `_pages` and `_galleries` directories are *required*. Lumen will not function correctly without them.

## Build Command

To generate your static site, navigate to the root of your project directory in the terminal and run:

```bash
lumen build
```

This command processes all Markdown files from `_pages/`, creates galleries based on the contents of directories within `_galleries/`, generates thumbnails, extracts EXIF captions, and outputs the resulting HTML files into a new directory (configurable - see below).

## Local Preview Server

To quickly preview your portfolio locally with live reloading during development, use:

```bash
lumen serve
```

This will start a local web server (typically on `http://localhost:4567/`) and automatically refresh the browser whenever you make changes to your content or configuration.  Stop the server by pressing Ctrl+C in the terminal.

## EXIF Caption Extraction

Lumen automatically extracts captions from your images using the EXIF tag `ImageDescription`. **This is crucial for automatic captioning!** Ensure that this tag contains a descriptive caption when you save your photos.

For example, if `photo1.jpg` has an `ImageDescription` of "Eiffel Tower at sunset", Lumen will display "Eiffel Tower at sunset" as the caption for that image in the gallery.  If the `ImageDescription` is missing or empty, no caption will be displayed.

## Configuration (lumen.yml)

Configuration options are managed through a single YAML file named `lumen.yml` located at the root of your project directory. This file allows you to customize the site title, theme (future), and output directory.

**Example `lumen.yml`:**

```yaml
title: "My Photography Portfolio"
output_dir: "_site"  # Where the generated HTML files will be placed
# theme: minimal # Future feature - specify a theme name here
```

* **`title`**: Sets the title of your portfolio, which is used in the `<title>` tag and potentially other header elements.
* **`output_dir`**: Specifies the directory where the generated HTML files will be placed. The default value is `_site`. You can change it to any desired location. *This directory must not already exist.*  Lumen will create it for you.
* **`theme`**: (Future Feature) This option will allow users to choose from pre-built themes to quickly customize the look and feel of their portfolio. Currently, Lumen uses a default theme.
