# phodedupe - Find Duplicate Photos with Perceptual Hashing

phodedupe is a command-line tool written in Python that identifies duplicate photos within one or more directories. Unlike simple checksum comparisons (like MD5 or SHA256), it utilizes perceptual hashing, making it robust to minor variations like resizing, recompression, color adjustments, and even watermarks – common scenarios where images are technically different but visually identical.

## Why Perceptual Hashing?

Standard checksums treat even a single pixel change as a completely different file.  This means resized or slightly altered copies of the same photo would be considered unique. Perceptual hashing (pHash) calculates a fingerprint based on the *visual* content of an image, making it much more forgiving to these common modifications. Images that are visually similar will have similar pHashes, even if their file sizes and checksums differ significantly.

## Installation

Install phodedupe using pip:

```bash
pip install phodedupe
```

Ensure you have Python 3.7 or higher installed.

## Basic Usage

After installation, you can scan a directory for duplicates with the following command:

```bash
phodedupe /path/to/your/photo/directory
```

This will:

1. **Scan:**  Analyze all image files within `/path/to/your/photo/directory`. Supported formats include JPEG, PNG, and GIF (more may be added).
2. **Generate Hashes:** Calculate a perceptual hash for each image.
3. **Group Duplicates:**  Identify groups of images with similar hashes.
4. **Report Groups:** Display a report in the console showing potential duplicate groups. Each group will list the file paths of the identified duplicates.

**Reviewing Before Deletion (Crucially Important!)**

*phodedupe* is designed to *identify* duplicates, not automatically delete them.  **Always carefully review the reported groups before taking any action!**  False positives can occur, especially with unusual images or aggressive similarity thresholds (see Configuration Options below).

## Dry Run Mode

To preview what *would* happen without actually deleting anything, use the `--dry-run` flag:

```bash
phodedupe --dry-run /path/to/your/photo/directory
```

This will produce the same report as above but add a "DRY RUN" prefix to each identified file path.

## Configuration Options

* **Hash Algorithm (`--hash-algorithm`):**  Choose from different pHash algorithms.  The default is `average_hash`. Other options (implementation dependent) might include `phash`, `dhash`, `whash`, and `xhash`. Experiment to find the algorithm that best suits your needs.

   ```bash
   phodedupe --hash-algorithm phash /path/to/your/photo/directory
   ```

* **Similarity Threshold (`--similarity`):**  Control how similar hashes need to be for images to be considered duplicates. The default is 0.85 (85% similarity). Lower values will identify more potential duplicates, but increase the risk of false positives. Higher values are stricter and may miss subtle variations. A value between 0.75 and 0.95 is generally recommended.

   ```bash
   phodedupe --similarity 0.9 /path/to/your/photo/directory
   ```

* **Directory List:**  You can specify multiple directories to scan:

   ```bash
   phodedupe /path/to/dir1 /path/to/dir2 /path/to/dir3
   ```
