# wavtag - A WAV Metadata Library

wavtag is a small, single-header C library designed to read and write metadata chunks (LIST/INFO tags) within WAV audio files without modifying the actual audio sample data. It provides a simple API for accessing and manipulating standard chunk types like `RIFF`, `fmt `, `data`, `ilst` (for INFO chunks), and custom LIST chunks.

## Features:

*   **Non-destructive metadata editing:**  Only metadata is manipulated; audio data remains untouched.
*   **Simple API:** Easy to integrate into existing projects with a single header file.
*   **Support for standard WAV chunk types:** Handles `RIFF`, `fmt `, `data`, and especially, INFO chunks (`ilst`).
*   **Custom LIST chunk handling:** Allows reading and writing of arbitrary LIST-formatted data.
*   **Portable (with byte-order considerations - see below).**

## Build Instructions:

The library is designed to be easily built with a standard C compiler.  A `Makefile` is provided for convenience.

```bash
make
```

This will compile `wavtag.h` into `libwavtag.a`. To install the library (copying the header), run:

```bash
make install
```

You'll need a C compiler like GCC or Clang to build.  No external dependencies are required beyond a standard C toolchain.

## Public API:

The entire API is exposed in `wavtag.h`. Here are the key functions:

*   **`wt_open(const char *filename)`:** Opens a WAV file for reading and writing. Returns a pointer to a `wt_context` structure on success, or `NULL` on failure.  Call `wt_close()` when finished.
*   **`wt_close(wt_context *ctx)`:** Closes the opened WAV file context.
*   **`wt_get_chunk_size(wt_context *ctx, const char *chunk_id)`:** Returns the size of a specific chunk identified by `chunk_id`.  Returns 0 if the chunk is not found.
*   **`wt_read_ilst(wt_context *ctx, int ilst_index, char **data, size_t *size)`:** Reads a single INFO chunk (ILST) at the specified index. Populates `data` with a pointer to the chunk data and `size` with its size.  Returns 0 on success, non-zero on failure.
*   **`wt_write_ilst(wt_context *ctx, int ilst_index, const char *data, size_t size)`:** Writes an INFO chunk (ILST) at the specified index. This will overwrite any existing ILST at that index or insert a new one if `ilst_index` is larger than the current number of ILSTs.
*   **`wt_save(wt_context *ctx)`:**  Saves changes to the WAV file.

## Byte-Order Handling:

WAV files often store metadata chunk sizes and data as little-endian values, even on big-endian systems. `wavtag` attempts to handle this by providing a compile-time option (`#define WT_SWAP_ENDIAN`) which you should enable if your target platform is big-endian.  This is best handled during compilation rather than runtime for performance reasons.

```c
#ifdef __BYTE_ORDER__ == __LITTLE_ENDIAN__
  // No endian swap needed
#else
  #define WT_SWAP_ENDIAN 1
#endif
```

This will typically be handled automatically if you are compiling on a big-endian system. Check the `wavtag.h` header for details.
