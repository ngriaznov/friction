## Quillfeather - Keyboard Shortcut Reference

This document details the available keyboard shortcuts for Quillfeather, a terminal-based text editor. These shortcuts are designed to maximize efficiency when working within the editor.  Please note that key combinations may be affected by your terminal's own settings (e.g., Ctrl binding).

**I. Navigation Shortcuts:**

These shortcuts allow you to move around the document quickly and easily.  `Ctrl` represents the Control key, `Alt` represents the Alt/Option key, and `Tab` is the Tab key.

* **Movement within a Line:**
    * `Left`: Move cursor one character left.
    * `Right`: Move cursor one character right.
    * `Home`: Move cursor to the beginning of the line.
    * `End`: Move cursor to the end of the line.
* **Vertical Movement:**
    * `Up`: Move cursor up one line.
    * `Down`: Move cursor down one line.
    * `Page Up`: Move cursor up one screenful (24 lines by default).
    * `Page Down`: Move cursor down one screenful.
* **Word-Based Movement:**
    * `Alt + Left`: Move cursor backward one word.
    * `Alt + Right`: Move cursor forward one word.  (Note: May require Alt key configuration in your terminal.)
* **Document Boundaries:**
    * `Ctrl + Home`: Move cursor to the beginning of the document (first line).
    * `Ctrl + End`: Move cursor to the end of the document (last line).

**II. Editing Shortcuts:**

These shortcuts allow you to insert, delete, and modify text.

* **Insertion & Deletion:**
    * `Insert` / `Ins`: Toggle insertion mode (overwriting existing characters) versus append mode.  Indicated by a visual cue in the status bar.
    * `Backspace`: Delete character to the left of the cursor.
    * `Delete`: Delete character to the right of the cursor.
    * `Ctrl + D`: Delete character under the cursor (equivalent to Delete). Useful when insert mode is active and overwrite behavior is desired.
* **Text Manipulation:**
    * `Ctrl + K`: Cut from the cursor position to the end of the line.  Cut text is stored in a temporary buffer for potential pasting.
    * `Ctrl + U`: Paste the contents of the cut buffer before the cursor.
    * `Ctrl + W`: Cut word (from cursor leftwards).
    * `Alt + D`: Delete word (from cursor rightwards). (Note: May require Alt key configuration.)
    * `Ctrl + A`: Select all text in the document.
* **Undo/Redo:**
    * `Ctrl + Z`: Undo last action.
    * `Ctrl + Shift + Z`: Redo last undone action.

**III. Search Shortcuts:**

These shortcuts enable searching within the current file.  Search functionality is initiated by entering search mode (usually via a menu option).

* **Searching Forward:**
    * `Ctrl + F`: Find next occurrence of the search term.
* **Searching Backward:**
    * `Ctrl + B`: Find previous occurrence of the search term.
* **Case Sensitivity & Wrap-Around:**  (Often toggled via menu options, but may have keyboard shortcuts depending on configuration)
    * (Example: `Alt + S` - Toggle Case Sensitive Search – this is a configurable option).

**IV. Window Management Shortcuts:**

These shortcuts manage the editor’s windows and behavior.

* **Saving & Loading:**
    * `Ctrl + S`: Save the current file.
    * `Ctrl + L`: Load a file (prompts for filename).
* **File Operations:**
    * `Ctrl + N`: Create a new, empty file.
* **Quitting:**
    * `Ctrl + Q`: Quit Quillfeather and prompt to save changes if any.
* **Status Bar & Information:**
    *  `Alt + I` (Example): Toggle display of the Status Bar – showing line number, cursor position, and mode information. This is a configurable option.



**Note:** Some shortcuts might be customizable within Quillfeather’s configuration file. Refer to the dedicated configuration documentation for details on customizing these actions. The `Help` menu provides access to more detailed explanations and further customization options.
