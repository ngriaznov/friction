## Getting Started with `dedupe-shots`: Clean Up Your Photo Library

`dedupe-shots` is a command-line tool designed to help you identify and remove duplicate photos in your local photo library. It uses perceptual hashing (phash) – a clever technique that compares images based on their visual content rather than just file names or sizes, allowing it to detect duplicates even if they’ve been renamed or slightly edited. This guide will get you up and running quickly.

**1. Installation:**

`dedupe-shots` is written in Python and requires Python 3.6 or higher.  It uses `pip`, the standard Python package installer, for installation.

* **Prerequisites:** Make sure you have Python 3 installed. You can check by opening your terminal (or command prompt on Windows) and typing: `python3 --version` or `python --version`. If it’s not installed, download it from [https://www.python.org/downloads/](https://www.python.org/downloads/).

* **Installation via pip:** Open your terminal and run the following command:

   ```bash
   pip3 install dedupe-shots
   ```

   (On some systems, you might need to use `pip` instead of `pip3`). This will download and install `dedupe-shots` along with its dependencies.

**2. Basic Usage - Scanning Your Photo Library:**

The core functionality of `dedupe-shots` is scanning a directory for potential duplicates.  Here's how:

* **Navigate to your photo library directory:** Use the `cd` command in your terminal to navigate to the folder containing all the photos you want to analyze. For example:

   ```bash
   cd /Users/yourusername/Pictures/MyPhotos
   ```

* **Run a basic scan:** Execute the following command, replacing `<directory>` with the path to your photo library if you're not already in it:

   ```bash
   dedupe-shots scan <directory>
   ```

   For example (if scanning `/Users/yourusername/Pictures/MyPhotos`):

   ```bash
   dedupe-shots scan /Users/yourusername/Pictures/MyPhotos
   ```

  This will:

    * Calculate perceptual hashes for each image in the directory.
    * Compare these hashes to find potential duplicates based on a similarity threshold (default is 0.95 – meaning images need to be 95% visually similar to be considered duplicates).
    * Print a list of groups of potentially duplicate images to your terminal, along with their file paths and phash values.

**3. Previewing Matches Before Deletion - The `preview` Command:**

Before you delete anything, it’s *crucial* to review the identified matches!  `dedupe-shots` provides a preview mode for exactly this purpose.

* **Run the preview command:** After running the `scan` command, use this:

   ```bash
   dedupe-shots preview
   ```

   This will open an interactive viewer in your terminal (or potentially a new window depending on your system). You'll see images grouped based on their perceived similarity.  You can navigate between groups and individual images within each group using the arrow keys or other navigation methods provided by the viewer.

* **Review carefully:** Examine each image within a group to determine if they are truly duplicates.  Remember, perceptual hashing isn’t perfect - occasional false positives (images incorrectly identified as duplicates) *can* occur.

**4. Deleting Duplicates – The `delete` Command (Use with Caution!):**

Once you've reviewed the matches and are confident that a group represents true duplicates, you can delete them. **This is irreversible, so double-check everything before proceeding!**

* **Run the deletion command:** After previewing and confirming the groups you want to remove, execute:

   ```bash
   dedupe-shots delete <group_number>
   ```

   Replace `<group_number>` with the number of the group you wish to delete.  The group numbers are displayed in the output of the `scan` command and during the `preview`. For example, if you want to delete group #3:

    ```bash
    dedupe-shots delete 3
    ```

   By default, `dedupe-shots` will keep the *first* image in each group and delete the rest.  You can customize this behavior with additional options (see below).

**Further Options & Customization:**

* **Adjusting Similarity Threshold:** Use `--threshold <value>` to change the similarity threshold for identifying duplicates. Lower values are more aggressive, higher values are more conservative. Example: `dedupe-shots scan --threshold 0.85`
* **Keeping a Different Image:** The `--keep-first` flag (enabled by default) determines which image in a group is preserved.  You can use `--keep-last` to keep the last image instead.
* **Dry Run:** Use `--dry-run` to see what *would* be deleted without actually deleting anything. This is highly recommended before running `delete`.

**For more detailed information and advanced options, consult the full documentation using `dedupe-shots --help`.**



Remember to back up your photo library before running any duplicate removal tool!  Happy cleaning!
