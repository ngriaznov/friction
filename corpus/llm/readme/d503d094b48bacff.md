# soilwatch

Arduino firmware for a battery-powered soil moisture sensor. Logs readings to an SD card on a fixed interval and can optionally report them over a low-power radio link, so the sensor can be buried in a garden bed or a field plot without a wired connection.

## Hardware required

- A capacitive soil moisture probe (resistive probes work but corrode within a season of continuous burial and are not recommended)
- An Arduino-compatible board with SPI (an Arduino Nano or Pro Mini is the usual choice for the low current draw)
- An RTC module (DS3231 recommended for temperature-compensated timekeeping) so log timestamps survive power loss and stay accurate over months of unattended deployment
- An SD card breakout board wired over SPI
- Optionally, a low-power radio module (this firmware targets an RFM69-style module) for reporting readings to a base station without walking out to the sensor

## Wiring

The probe's analog output goes to one of the board's analog input pins (A0 by default, configurable). The RTC module and SD breakout both share the SPI/I2C bus as appropriate to their interface — the RTC over I2C (SDA/SCL), the SD card over SPI (MOSI/MISO/SCK plus a dedicated chip-select pin). The radio module, if used, takes its own chip-select pin on the same SPI bus. All three peripherals can share the bus because each has an independent chip-select line; only one device is addressed at a time. Power the probe only while taking a reading (via a digital output pin acting as a switch) rather than continuously, since capacitive probes draw meaningfully less current when unpowered between samples — this is the single biggest factor in battery life.

## Flashing

Open `soilwatch.ino` in the Arduino IDE, select your board and port under Tools, and upload. The sketch has no external library dependencies beyond the standard SD, RTC, and (if using the radio) RFM69 libraries, all installable through the Library Manager.

## Configuration

Before flashing, edit the constants block near the top of `soilwatch.ino`:

- `SAMPLE_INTERVAL_MINUTES` — how often to take and log a reading. Defaults to 30.
- `DRY_RAW` and `WET_RAW` — the raw analog readings corresponding to the probe fully dry and fully submerged, used to calibrate readings to a 0–100% scale. Calibrate these per probe by taking a reading in open air and a reading in a cup of water.
- `RADIO_ENABLED` — set to 0 to disable the radio and save power if you'll retrieve the SD card manually instead.

## Reading the log

Readings are appended to `LOG.CSV` on the SD card, one row per sample: timestamp, raw analog value, and calibrated percentage. Pull the card and open the file in any spreadsheet program, or parse it with a simple script — no special tooling is required.
