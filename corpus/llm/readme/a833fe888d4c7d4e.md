# wxcli

Current airport weather in your terminal. `wxcli` fetches the public METAR feed for an ICAO station, decodes it into plain English, and prints the raw observation underneath so you can check its work.

## Install

```
go install github.com/example/wxcli@latest
```

Or grab a static binary from the releases page. No config file, no API key — the METAR feed is public.

## Usage

Pass an ICAO airport code:

```
$ wxcli KSEA
Seattle-Tacoma Intl (KSEA) — observed 18:53Z, 12 min ago

  Temperature   9°C (dew point 7°C, humidity 87%)
  Wind          from 200° at 12 kt, gusting 19 kt
  Visibility    10 SM or greater
  Clouds        broken at 1,800 ft, overcast at 3,400 ft
  Altimeter     29.86 inHg / 1011 hPa

  KSEA 011853Z 20012G19KT 10SM BKN018 OVC034 09/07 A2986
```

Lowercase codes work too — `wxcli ksea` is the same thing. Three-letter IATA codes are not supported; use the four-letter ICAO identifier.

The decoded fields are temperature and dew point (with relative humidity computed from the two), wind direction and speed with gusts when reported, prevailing visibility, and cloud layers from lowest to highest. If the station reports present weather — rain, mist, thunderstorms — it appears as its own line above Clouds. Anything `wxcli` doesn't recognize in the remarks section is left out of the summary but stays visible in the raw string.

## Scripting

`--raw` suppresses the decoded block entirely and prints just the METAR, one line, no color:

```
$ wxcli --raw KSEA
KSEA 011853Z 20012G19KT 10SM BKN018 OVC034 09/07 A2986
```

Useful for piping into something else, or for a status bar. Exit code is 0 on success, 2 if the station is unknown, and 3 if the feed is unreachable — so a shell script can tell "no such airport" from "no network."

## Notes

Observations are typically issued hourly, near the top of the hour, with special reports in between when conditions change. The "observed … ago" line tells you how stale the data is. `wxcli` caches nothing; every invocation is a fresh fetch.
