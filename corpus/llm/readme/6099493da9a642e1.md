# org-habitctl

Habit tracking for org-mode with streak counters and a weekly review buffer.

`org-habit` ships with Emacs and does one thing well: it shows a consistency graph in the agenda. `org-habitctl` builds on top of it for people who want the other things — how long is my current streak, what did I miss last week, and which habits am I quietly abandoning. It does not replace `org-habit`; it reads the same `STYLE: habit` entries and adds commands and a review buffer alongside them.

## Installation

From MELPA:

```
M-x package-install RET org-habitctl RET
```

With `use-package` and `straight.el`:

```elisp
(use-package org-habitctl
  :straight (:host codeberg :repo "kmr/org-habitctl")
  :after org
  :config (org-habitctl-mode 1))
```

## Configuration

The minimum viable setup in `init.el`:

```elisp
(require 'org-habitctl)
(setq org-habitctl-files '("~/org/habits.org"))
(org-habitctl-mode 1)
```

`org-habitctl-files` defaults to `org-agenda-files` if unset, which is usually fine but scans more than you need. Pointing it at a dedicated file makes the review buffer noticeably faster on large agendas.

Two other variables are worth knowing:

- `org-habitctl-week-start` — `'monday` (default) or `'sunday`. Affects the weekly review boundaries only.
- `org-habitctl-grace-days` — integer, default `0`. Number of missed days tolerated before a streak resets. Set to `1` if you want a forgiving definition of "daily."

## Key bindings

`org-habitctl-mode` is a global minor mode and binds nothing by default. Suggested bindings:

```elisp
(define-key org-habitctl-mode-map (kbd "C-c h d") #'org-habitctl-mark-done)
(define-key org-habitctl-mode-map (kbd "C-c h s") #'org-habitctl-show-streak)
(define-key org-habitctl-mode-map (kbd "C-c h r") #'org-habitctl-review)
```

| Command | Description |
|---|---|
| `org-habitctl-mark-done` | Marks the habit at point done for today. With `C-u`, prompts for a date. |
| `org-habitctl-show-streak` | Echoes current and longest streak for the habit at point. |
| `org-habitctl-review` | Opens the weekly review buffer. |
| `org-habitctl-mark-skipped` | Records an intentional skip; does not break the streak. |

The review buffer (`*Habit Review*`) lists each habit with its completion count for the week, current streak, and a seven-column grid of the last week. `RET` on a row jumps to the org entry. `g` refreshes. `q` buries the buffer.

## Storage format

Everything lives in org properties on the habit heading. Nothing is stored outside your org files, and no database or cache file is written.

```org
* TODO Morning pages
  SCHEDULED: <2031-03-14 Fri .+1d>
  :PROPERTIES:
  :STYLE:            habit
  :HABITCTL_TARGET:  daily
  :HABITCTL_STREAK:  23
  :HABITCTL_BEST:    41
  :HABITCTL_SKIPS:   2031-02-08 2031-02-09
  :END:
```

`HABITCTL_TARGET` accepts `daily`, `weekly`, or `Nx-weekly` (for example `3x-weekly`). The streak and best-streak properties are recomputed from the `LOGBOOK` drawer whenever you mark a habit done, so hand-editing them is harmless but pointless. `HABITCTL_SKIPS` is a space-separated list of dates recorded by `org-habitctl-mark-skipped`.

Because completions are read from `LOGBOOK`, habits you have been tracking with plain `org-habit` will already have full streak history when you enable this package. No import step.
