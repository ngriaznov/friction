# nbtidy

Format the code cells in a Jupyter notebook every time you save it. Markdown cells and cell outputs are left exactly as they were.

nbtidy exists because notebooks are where formatting discipline goes to die. You paste something from Stack Overflow, you tweak it inline, you never run a formatter because running one means dropping to a terminal and reformatting the `.ipynb` JSON. This just does it on Ctrl+S.

## Install

```
pip install nbtidy
jupyter server extension enable nbtidy
```

Restart the Jupyter server. That's the whole setup — there's no client-side extension to build, so it works in JupyterLab, Notebook 7, and anything else running against the same server.

To confirm it loaded:

```
jupyter server extension list | grep nbtidy
```

## What it uses

Under the hood nbtidy shells out to [Black](https://github.com/psf/black). It does not implement its own formatting rules and has no intention of ever doing so. If Black formats it a certain way, so does nbtidy.

Two notebook-specific accommodations: cells containing IPython magics (`%timeit`, `%%bash`) and shell escapes (`!pip install ...`) are passed through untouched, since Black can't parse them. A cell that fails to parse for any other reason — a syntax error you're mid-way through fixing — is also left alone. Saving a broken notebook never destroys your work.

## Excluding a cell

Put `# nbtidy: skip` anywhere in a cell and nbtidy won't touch it:

```python
# nbtidy: skip
matrix = [
    [1, 0, 0],
    [0, 1, 0],
    [0, 0, 1],
]
```

Useful for hand-aligned data literals, teaching examples where the odd spacing is the point, and cells you're actively arguing with.

## Line length

The one configuration option. In `jupyter_server_config.py`:

```python
c.NbTidy.line_length = 100
```

Default is 88, matching Black's. Set it to whatever your repo's `pyproject.toml` says so notebooks and modules agree.

If nbtidy finds a `pyproject.toml` with a `[tool.black]` section in the notebook's directory or any parent, that file wins over the Jupyter config. This is deliberate — the repo's setting should be the source of truth.

## Turning it off

```
jupyter server extension disable nbtidy
```

Or, for a single session, set `c.NbTidy.enabled = False`.
