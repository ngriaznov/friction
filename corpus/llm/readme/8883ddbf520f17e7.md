# cardbox

A spaced-repetition flashcard reviewer for the terminal. Decks are plain YAML files, so you can edit them in your editor, keep them in git, or generate them from a script.

## Install

```
cargo install cardbox
```

Or grab a prebuilt binary from the releases page and drop it on your `PATH`. Decks live wherever you point cardbox; review state is kept in `~/.local/state/cardbox/` and never written back into your deck files.

## Deck format

A deck is a YAML file with a `name` and a list of `cards`. Each card needs `front` and `back`; `tags` are optional.

```yaml
name: Kanji N5
cards:
  - front: 山
    back: mountain / yama
    tags: [nature, jouyou-1]

  - front: 川
    back: river / kawa
    tags: [nature, jouyou-1]

  - front: 日
    back: sun, day / hi, nichi
```

Multi-line backs work with the usual YAML block scalar:

```yaml
  - front: What does `git reset --soft HEAD~1` do?
    back: |
      Moves HEAD back one commit.
      Leaves the index and working tree untouched,
      so the changes stay staged.
```

Cards are identified by a hash of their `front` field. Editing a back, adding tags, or reordering the file preserves scheduling history. Editing a front creates a new card and retires the old one.

## Reviewing

```
cardbox review kanji-n5.yaml
```

Only cards that are due appear. The front is shown; press space to reveal the back, then grade yourself:

| Key | Meaning |
| --- | --- |
| `1` | Forgot it completely |
| `2` | Got it, but it was hard |
| `3` | Recalled it cleanly |
| `4` | Instant, felt trivial |

`e` opens the current card in `$EDITOR`, `s` skips without grading, and `q` quits — progress is saved after every card, so quitting mid-session loses nothing.

Filter by tag with `--tag nature`, or cap a session with `--limit 30`.

## Scheduling

Each card carries an interval and an ease factor, starting at 1 day and 2.5.

Grade `3` or `4` multiplies the interval by the ease factor and schedules the card that many days out; a `4` also nudges ease up by 0.15, a `3` leaves it alone. Grade `2` keeps the ease but only advances the interval by 20%, so hard cards come back soon. Grade `1` resets the interval to 1 day and drops ease by 0.2, with a floor of 1.3 so a card you keep failing doesn't collapse to reviewing forever.

New intervals get up to ±10% of random jitter, which stops a big import from clumping into one brutal day months later.

Run `cardbox due kanji-n5.yaml` for a count of what's waiting, or `cardbox stats` for the next fourteen days of scheduled load.
