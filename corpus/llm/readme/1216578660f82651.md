# phodedupe

Find duplicate photos across one or more directories, including copies that have been resized, re-compressed, or exported at a different quality setting.

## Why not just compare checksums?

An MD5 or SHA-256 comparison only catches files that are byte-for-byte identical. That misses almost every duplicate people actually accumulate: the 1024px version your chat app made, the JPEG you re-saved after a crop-free rotation, the copy Lightroom exported at 90% quality instead of 100%. Change a single pixel and the checksum is unrelated to the original's.

A perceptual hash describes the *image*, not the file. phodedupe downscales each photo, converts it to grayscale, and derives a compact fingerprint from the result. Two images that look the same to a human produce fingerprints that differ in only a few bits, so similarity becomes a Hamming distance you can threshold.

## Install

```
pip install phodedupe
```

Python 3.9 or newer. Pillow is pulled in automatically; install `phodedupe[raw]` if you need CR2/NEF/ARW support.

## Usage

Scan a folder and print a report of duplicate groups:

```
phodedupe scan ~/Pictures
```

Output looks like this:

```
Group 3 — 3 files, max distance 4
  keep  4000x3000  4.1 MB  Pictures/2022/beach-042.jpg
        1600x1200  620 KB  Pictures/exports/beach-042.jpg
        1600x1200  588 KB  Desktop/beach.jpg
```

The `keep` file is chosen by resolution, then file size, then oldest mtime. Nothing has been touched at this point — `scan` is read-only.

Scan several roots at once by passing more paths. Symlinks are not followed.

To delete, write the report to a file, edit it (delete any line you want to keep), and apply it:

```
phodedupe scan ~/Pictures -o report.txt
phodedupe apply report.txt --dry-run
phodedupe apply report.txt
```

`--dry-run` prints exactly what would be removed and exits without changing anything. Please use it the first time.

## Configuration

| Flag | Default | Notes |
|---|---|---|
| `--algorithm` | `dhash` | `dhash`, `phash`, `ahash`, `whash` |
| `--threshold` | `6` | Max Hamming distance within a group |
| `--hash-size` | `8` | Produces a 64-bit hash; `16` is slower and stricter |
| `--workers` | CPU count | Hashing is parallel, I/O is not |
| `--min-size` | `20KB` | Skip thumbnails and icons |

`dhash` is fast and good enough for most libraries. `phash` handles heavy compression artifacts better at roughly 3x the cost. If you shoot bursts, drop `--threshold` to 3 or 4 — consecutive frames are visually near-identical and will otherwise land in the same group.

Settings can also live in `~/.config/phodedupe.toml`.
