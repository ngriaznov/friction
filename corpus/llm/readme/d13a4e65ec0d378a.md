# tasq

A todo manager that keeps your tasks in a plain text file, one task per line. No database, no sync service, no lock file. You can read it with `cat`, edit it in vim, and commit it to git — and a diff of your todo list is actually readable.

## Why plain text

Because the file outlives the tool. If tasq stops being maintained tomorrow, your data is still a text file you can open. And because line-oriented storage means version control does something useful with it: `git log -p todo.txt` is a genuine history of what you meant to do and when you stopped meaning it.

## Install

```
go install github.com/mhalloran/tasq@latest
```

## Usage

Add a task:

```
tasq add "renew passport"
```

List everything open:

```
tasq ls
```

Complete task 3:

```
tasq done 3
```

Completed tasks stay in the file with an `x ` prefix rather than being deleted. `tasq ls` hides them; `tasq ls --all` doesn't.

## Tags and due dates

Tags are words prefixed with `@`, written inline anywhere in the task text:

```
tasq add "book flights @travel @urgent"
```

Due dates use `due:` followed by an ISO date or a relative shorthand (`today`, `tomorrow`, `fri`, `+3d`):

```
tasq add "submit expenses due:fri @work"
```

Relative dates are resolved when the task is added and stored as an absolute date, so they don't drift.

## Filtering

```
tasq ls @work              # tasks tagged @work
tasq ls @work @urgent      # tasks with both tags
tasq ls --due today        # due today or earlier
tasq ls --overdue          # past due, still open
tasq ls --no-due           # no due date set
```

Filters combine, so `tasq ls @work --overdue` does what it looks like.

## Where the file lives

By default, `~/.tasq/todo.txt`. It's created on first write.

Point tasq somewhere else with `TASQ_FILE`:

```
export TASQ_FILE=~/notes/todo.txt
```

This is the usual way to keep a project todo list inside a repo — set `TASQ_FILE` in a direnv `.envrc` and tasq follows you into the project directory.
