# Lumen

Lumen is a static site generator built specifically for photography portfolios. It skips the general-purpose blogging conventions most site generators assume and instead treats a gallery of images as the fundamental unit of a site. Distributed as a Ruby gem, it aims to get a photographer from a folder of JPEGs to a fast, clean portfolio site with almost no configuration.

## Folder convention

Lumen expects a predictable project layout:

```
my-site/
  config.yml
  pages/
    index.md
    about.md
  galleries/
    iceland-2025/
      images/
        glacier-01.jpg
        glacier-02.jpg
        aurora-01.jpg
      gallery.yml
    portraits/
      images/
        ...
      gallery.yml
```

Each gallery is a directory under `galleries/` containing an `images/` subdirectory and a small `gallery.yml` file with the gallery's title, sort order, and cover image. Pages live under `pages/` as plain Markdown files with no front matter — Lumen deliberately keeps page content separate from site metadata, which all lives in `config.yml` and each gallery's `gallery.yml`. This split means a photographer editing prose doesn't need to touch YAML, and someone managing site structure doesn't need to touch Markdown.

## Building and previewing

Build the site with:

```
lumen build
```

This renders everything into `_site/`, ready to upload to any static host. For local development, run:

```
lumen serve
```

which starts a preview server at `http://localhost:4000` and watches the `pages/` and `galleries/` directories for changes, rebuilding automatically so you can see edits without restarting the server.

## Thumbnails and EXIF captions

The most Lumen-specific feature is automatic thumbnail generation paired with EXIF-based captions. On build, Lumen generates three thumbnail sizes per image (grid, lightbox-preview, and full-resolution-optimized) using `libvips` under the hood for speed, and caches them in `.lumen-cache/` so repeat builds only regenerate images that changed.

For captions, Lumen reads each image's EXIF data and can auto-populate a caption line with camera model, lens, and exposure settings — useful for photographers who want that information visible without typing it out per image. This is opt-in per gallery via the `exif_captions: true` key in `gallery.yml`, and any caption you write manually in that file takes precedence over the auto-generated one.

## Site configuration

All site-wide settings live in a single `config.yml` at the project root:

```yaml
title: "Maren Hollis Photography"
theme: "monochrome"
output_dir: "_site"
galleries_order:
  - iceland-2025
  - portraits
  - urban-studies
```

The `theme` key selects one of Lumen's built-in themes (`monochrome`, `gallery-grid`, and `full-bleed` ship by default), `output_dir` controls where the built site is written, and `galleries_order` controls the order galleries appear on the homepage — omit it and Lumen falls back to alphabetical order.

## Installation

```
gem install lumen-ssg
```

Ruby 3.0 or later is required, along with `libvips` installed on your system for thumbnail generation (`brew install vips` on macOS, `apt install libvips` on Debian/Ubuntu).

## Getting started

```
lumen new my-site
cd my-site
lumen serve
```

`lumen new` scaffolds the folder structure above with a sample gallery and starter theme, so you can see a working site before adding your own images.
