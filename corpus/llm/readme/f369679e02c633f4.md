# lumen

A static site generator for photography portfolios. No front matter, no shortcodes, no template language to learn — you organize your photos into folders and lumen builds the site.

Most static site generators are built for text and treat images as an afterthought you paste into Markdown. lumen inverts that: galleries are the primary unit, pages are optional, and the metadata your camera already wrote into the file is used instead of asking you to retype it.

## Install

```
gem install lumen
```

Ruby 3.1 or newer. Thumbnail generation shells out to ImageMagick, so you'll need `magick` on your `PATH`.

## Folder convention

lumen infers the entire site structure from the filesystem. A project looks like this:

```
my-portfolio/
├── lumen.yml
├── galleries/
│   ├── iceland-2024/
│   │   ├── 001-vestrahorn.jpg
│   │   ├── 002-jokulsarlon.jpg
│   │   └── 003-reynisfjara.jpg
│   └── street-tokyo/
│       ├── shibuya-crossing.jpg
│       └── golden-gai.jpg
└── pages/
    ├── about.md
    └── prints.md
```

Each directory under `galleries/` becomes one gallery. The directory name becomes the URL slug, and a title is derived from it (`iceland-2024` renders as "Iceland 2024"). Images are ordered by filename, which is why numeric prefixes are worth the trouble on sequenced work.

Each file under `pages/` becomes a standalone page at `/about/`, `/prints/`, and so on. These are plain Markdown with **no front matter** — the first `#` heading in the file is the page title. If you want to change the title, change the heading. There is nothing else to configure per page, and that is deliberate.

## Building

```
lumen build
```

Writes the finished site to `_site/` by default. The build is incremental: thumbnails are cached in `.lumen-cache/` and only regenerated when the source image's mtime and size change. A first build of 400 photos takes a couple of minutes; subsequent builds take under a second.

For local work:

```
lumen serve
```

Serves the site at `http://localhost:4000` and rebuilds on change. Adding a photo to a gallery directory triggers a rebuild of that gallery only. The browser reloads itself over a websocket, so you can drop files into a folder and watch them appear.

## Thumbnails

lumen generates three sizes for every image — a grid thumbnail, a lightbox-sized version, and the full-resolution original — and emits a `srcset` so browsers pick appropriately. Sizes are configurable but the defaults (400px, 1600px, original) suit most portfolio layouts.

Originals are copied through untouched. lumen never re-encodes or strips your full-size files, so if you want EXIF removed from what you publish, do it before the build.

## Captions from EXIF

If an image has an EXIF `ImageDescription` field, lumen uses it as the caption. Most cameras leave this blank; Lightroom, darktable, and Capture One all write to it when you fill in the caption field on export, which means your captions can live with the photos instead of in a separate text file.

Shooting details — camera body, lens, focal length, aperture, shutter, ISO — are read from EXIF and rendered under each image in the lightbox. Set `show_exif: false` to turn this off globally.

If a gallery directory contains a `caption.txt`, its contents become the gallery description shown above the grid.

## Configuration

Everything lives in `lumen.yml` at the project root:

```yaml
title: Marta Reyes Photography
theme: quiet
output_dir: _site
base_url: https://martareyes.com

show_exif: true
thumbnail_sizes: [400, 1600]
gallery_order:
  - iceland-2024
  - street-tokyo
```

`title` appears in the header and `<title>` tag. `theme` selects a bundled theme — `quiet` (white, minimal, one column), `grid` (dense masonry), or `dark` (full-bleed on black). `output_dir` is where the build lands. `base_url` is used for absolute links in the generated sitemap and feed; it can be omitted for local-only sites.

`gallery_order` controls the order galleries appear on the index. Anything not listed is appended alphabetically after the listed ones.

To customize a theme, run `lumen theme eject quiet`, which copies the theme's ERB templates and CSS into `_theme/` in your project. lumen prefers `_theme/` over the bundled version when it exists.
