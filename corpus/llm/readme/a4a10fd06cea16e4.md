# markpile

A self-hosted bookmarking service. Save a page with one click, find it later by tag. One binary, one SQLite file, no external dependencies.

## Install

Grab a release binary and run it:

```
curl -LO https://example.invalid/markpile/releases/markpile-linux-amd64
chmod +x markpile-linux-amd64
sudo mv markpile-linux-amd64 /usr/local/bin/markpile
markpile --db /var/lib/markpile/pile.db --listen 127.0.0.1:8710
```

The database file is created on first run. Put it somewhere your backups already reach — the entire service state is that one file, so `sqlite3 pile.db .dump` is a complete backup.

markpile does not terminate TLS or handle authentication itself. Run it behind a reverse proxy with HTTPS and HTTP basic auth, or on a host only reachable over your VPN. A 512 MB VPS is plenty; the process idles around 20 MB.

Create the first user before anyone can log in:

```
markpile --db /var/lib/markpile/pile.db useradd alice
```

## Storage

Everything lives in SQLite: bookmarks, tags, and a FTS5 index over title, URL, and description. Full-text search stays fast well past 50,000 bookmarks on modest hardware. There is no background job queue and no cache to invalidate.

## The web UI

The default view is a reverse-chronological list. The sidebar lists every tag with a count; clicking one filters the list. The search box accepts free text and `tag:` filters, and combines them:

```
tag:rust tag:parsing borrow checker
```

Multiple `tag:` terms are ANDed. Prefix a tag with `-` to exclude it. Free text is matched against title, URL, and description.

Editing a bookmark is inline — click the title, change the tags or description, press Enter.

## Bookmarklet

Go to **Settings → Bookmarklet** and drag the "Save to markpile" link to your browser's bookmarks bar. The generated link embeds your instance URL and a per-user token, so keep it as private as a password.

Clicking it on any page opens a small popup with the title and URL pre-filled and the cursor in the tag field. Enter tags separated by spaces, press Enter, and the popup closes. If the page is already saved, the popup opens in edit mode instead of creating a duplicate.

If your instance sits behind basic auth, the popup will prompt for those credentials the first time per browser session.

## Importing from a browser

markpile reads the Netscape bookmark file format, which is what Chrome, Firefox, and Safari all produce when you choose "Export bookmarks" — an HTML file full of `<DT><A HREF=...>` entries.

```
markpile --db /var/lib/markpile/pile.db import --user alice bookmarks.html
```

Folder names become tags, nested folders become multiple tags on the same bookmark, and the `ADD_DATE` attribute is preserved as the creation time. URLs that already exist for that user are skipped rather than duplicated; the import prints a count of added and skipped entries when it finishes.
