# soilwatch

soilwatch is Arduino firmware for a battery-powered soil moisture sensor.
It takes periodic readings from a capacitive moisture probe, timestamps
them using an RTC module, and logs them to an SD card as CSV. A radio link
is optional, for reporting readings without having to pull the SD card.

## Hardware

- An Arduino-compatible board (developed against a Pro Mini running at
  3.3V/8MHz for power reasons; any board with enough free pins and an SPI
  bus will work)
- A capacitive soil moisture probe (analog output, not the cheap resistive
  kind — resistive probes corrode within weeks of being left in soil)
- A DS3231 RTC module (I2C)
- A microSD breakout board (SPI)
- Optional: an nRF24L01+ radio module (SPI) for reporting readings without
  physically retrieving the card

## Wiring

The moisture probe's analog output goes to `A0`. The RTC module shares the
I2C bus (`SDA`/`SCL`) with nothing else on this project, so it just goes
to the board's default I2C pins. The SD breakout and the radio module both
use SPI and share `MOSI`/`MISO`/`SCK`, distinguished by separate chip
select lines: the SD card's `CS` goes to pin `4`, and the radio's `CSN`
goes to pin `9` (with its `CE` line on pin `8`). The radio and SD card
should not be read simultaneously — soilwatch's SPI transactions are
sequenced so only one device's CS line is asserted at a time, so sharing
the bus between them is safe as long as you don't rewire the CS
assignments without updating `PIN_SD_CS` and `PIN_RADIO_CSN` in the
firmware to match.

Power the moisture probe from a switched digital pin (`D7`) rather than
directly from Vcc — the firmware only energizes the probe for the brief
window it takes a reading, which is most of where the battery savings
come from versus leaving it powered continuously.

## Flashing

Open `soilwatch.ino` in the Arduino IDE, select your board and port under
Tools, and upload as normal. The sketch depends on three libraries
installable through the Library Manager: `RTClib`, `SD`, and (only needed
if you're using the radio) `RF24`.

## Configuration

Near the top of `soilwatch.ino`, a block of `#define` constants controls
behavior without needing to touch the rest of the code:

```cpp
#define SAMPLE_INTERVAL_MIN   30     // minutes between readings
#define PROBE_DRY_RAW         820    // raw ADC value in dry air
#define PROBE_WET_RAW         380    // raw ADC value fully submerged
#define RADIO_ENABLED         0      // set to 1 to enable radio reporting
```

`PROBE_DRY_RAW` and `PROBE_WET_RAW` calibrate the probe: take a reading
with the probe in open air for the dry value and one fully submerged in
water for the wet value, then update both constants. Every subsequent
reading is scaled linearly between them to produce a 0–100% moisture
figure rather than a raw ADC number that means nothing without context for
your specific probe.

## Reading the log

Readings are appended to `LOG.CSV` on the SD card, one line per sample:

```
timestamp,raw_adc,moisture_pct,battery_mv
2024-03-01T06:00:00,512,72,4021
2024-03-01T06:30:00,498,75,4019
```

`battery_mv` is measured off the board's own supply rail each cycle and is
useful for tracking when the battery needs replacing well before the
device actually browns out. The file opens fine in a spreadsheet or with
any CSV-aware tool — pull the card, copy `LOG.CSV`, put the card back.
