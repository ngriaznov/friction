# bootstat

Paired t-tests with bootstrapped confidence intervals for the mean difference.

`bootstat` is for the common small-sample case where you have paired measurements — before/after, treated/control on the same subject — and you'd like the familiar t-test output, but you don't fully believe the normality assumption behind its confidence interval. It runs the t-test and, alongside it, a nonparametric bootstrap over the paired differences, so you can see whether the two intervals agree. When they don't, that disagreement is itself informative.

## Installation

```r
install.packages("bootstat")
```

Depends on R >= 4.0. No dependencies outside base and `stats`.

## Example

The bundled `sleepgain` dataset records hours of extra sleep for 12 subjects under two drugs, measured on the same subjects a week apart.

```r
library(bootstat)

data(sleepgain)
head(sleepgain)
#>   subject drug_a drug_b
#> 1       1    0.7    1.9
#> 2       2   -1.6    0.8
#> 3       3   -0.2    1.1

fit <- boot_paired_t(sleepgain$drug_b, sleepgain$drug_a,
                     R = 10000, conf = 0.95, seed = 42)
fit
#> Paired t-test with bootstrap CI
#>
#>   mean difference:  1.58
#>   t = 4.062, df = 11, p = 0.00283
#>
#>   t interval  (95%):  [0.700, 2.460]
#>   bootstrap   (95%):  [0.842, 2.375]   (BCa, R = 10000)
```

The point estimate and p-value are identical to `t.test(paired = TRUE)` — the same computation, not a reimplementation. What's added is the second interval.

Here the bootstrap interval is slightly narrower and shifted, which is typical when the differences are mildly skewed: the t interval is symmetric by construction, the BCa interval is not.

## Function signature

```r
boot_paired_t(x, y, R = 2000, conf = 0.95, seed = NULL,
              type = c("bca", "percentile"))
```

- **`x`, `y`** — numeric vectors of equal length. Pairs with `NA` in either vector are dropped, with a message.
- **`R`** — number of bootstrap replicates. The default of 2000 is fine for exploration; use 10000 or more for anything you'll report, since BCa intervals are noticeably jumpy at low `R`.
- **`conf`** — confidence level for both intervals. Default `0.95`.
- **`seed`** — passed to `set.seed()` before resampling. Leave it `NULL` and results shift slightly between runs; set it and they don't. Set it in anything you intend to reproduce.
- **`type`** — `"bca"` (default) applies bias-correction and acceleration; `"percentile"` uses the raw quantiles of the replicate distribution. Percentile is faster and easier to explain; BCa is generally better behaved on skewed data.

## Compared to `t.test`

`t.test(x, y, paired = TRUE)` gives you one interval, derived from the t distribution, valid under normality of the differences. `boot_paired_t` gives you that same interval plus one that makes no distributional assumption, only that the pairs are independent draws.

With n below about 15 the bootstrap is not magic — it can only resample what you observed, and it will understate the tails of a distribution you sampled too sparsely to see. Treat a large gap between the two intervals as a signal to look at the data rather than as a verdict on which number to publish.

Accessors: `coef()`, `confint()`, and `print()` are defined. `confint(fit, method = "t")` returns the parametric interval if you want it separately.
