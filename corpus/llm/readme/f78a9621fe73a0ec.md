# abc2chord

Turn a tune written in ABC notation into a chord chart: the melody on one line, chord symbols sitting above it, printed as plain text or typeset to PDF.

It exists because session tunes circulate as ABC files, and what a guitar or bouzouki player actually wants on the music stand is not a full transcription — it's the shape of the tune with something to strum over.

## Installing

Requires Python 3.10 or later.

```
pip install abc2chord
```

PDF output additionally needs a working LaTeX installation with `lilypond-book` on the path. If you only want text charts, you can skip that; abc2chord will tell you clearly if you ask for a PDF without it.

## Basic usage

```
abc2chord cooleys.abc
```

That reads the first tune in the file and writes `cooleys.txt` next to it. For a specific tune in a multi-tune file, pass the X: index:

```
abc2chord session-set.abc --tune 3
```

Output looks like this:

```
Cooley's Reel                            Edor

|  Em                 |  D              |
   |: E2 BE dEBE      | E2 BE dEBd      |
|  Em                 |  D              |
   ~g2 fg edBd        | egdg BdBA       :|
```

Bar lines are aligned between the chord row and the note row, so a chord symbol always sits over the bar it applies to. Repeats, first and second endings, and part markers are carried through from the ABC source.

## Chord detection

If the ABC file already contains chord symbols in quotes — `"Em"E2 BE` — abc2chord uses them as-is and does nothing clever. That's always the best case, and if you're the one writing the ABC, put the chords in.

When there are no chords in the source, abc2chord guesses. The heuristic is deliberately simple, because a simple guess that's wrong in an obvious way is easier to correct than a sophisticated guess that's wrong subtly:

1. Read the `K:` field to establish the key, and build the set of diatonic triads for it.
2. Split the tune into bars, then into half-bars.
3. For each half-bar, weight every pitch by its duration, and give extra weight to notes on the beat and to the first and last note in the span.
4. Score each candidate triad by how much of that weight its chord tones account for.
5. Pick the winner, then apply two smoothing passes: collapse a half-bar chord into a whole-bar chord when both halves agree, and prefer the tonic on the final bar of a part.

The result is roughly what a competent accompanist would play on a first hearing of a modal Irish tune, which is to say mostly right and occasionally dull. It will not find secondary dominants, borrowed chords, or anything chromatic. Modal tunes in Dorian and Mixolydian are handled — the triad set comes from the mode implied by `K:`, not from the relative major.

Two flags adjust it:

- `--chords-per-bar 1|2` forces whole-bar or half-bar resolution instead of letting the smoothing pass decide.
- `--no-guess` leaves the chord row blank where the source has no chords, which is what you want if you'd rather pencil them in yourself.

## Output formats

```
abc2chord tune.abc --format text     # default
abc2chord tune.abc --format pdf
abc2chord tune.abc --format pdf --paper a4 --columns 2
```

**text** is monospaced, wraps at 80 columns by default (`--width`), and is what you want for pasting into a forum post or an email to the rest of the band.

**pdf** engraves the melody as actual notation with chord symbols above the staff. `--columns 2` fits a short reel onto half a page; `--paper` accepts `a4` or `letter`. Add `--title-from-file` to use the filename rather than the `T:` field as the heading, which is handy when someone has sent you twelve files all titled "Untitled".

Both formats accept `--transpose N` in semitones, applied before chord detection so the symbols come out in the new key.

## Limitations

Tune-body ABC only — abc2chord does not handle lyrics (`w:` lines), multiple voices (`V:`), or grace-note beaming beyond passing it to the engraver. Anything it can't parse is reported with a line number rather than skipped silently.
