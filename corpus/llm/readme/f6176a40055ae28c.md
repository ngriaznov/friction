# wavtag

wavtag is a small C library for reading and writing metadata in WAV audio
files — specifically the LIST/INFO chunk that carries tags like artist,
title, and comment. It only touches the metadata chunk; the audio sample
data (`data` chunk) is read and rewritten byte-for-byte untouched.

## Building

```
make
make install
```

This builds `libwavtag.a` (static) and `libwavtag.so` (shared) and
installs headers to `/usr/local/include` and libraries to
`/usr/local/lib` by default. Override with `PREFIX=/path make install` if
you want them somewhere else.

No external dependencies — wavtag only needs a C99 compiler and libc.

## API

```c
#include <wavtag.h>

wavtag_file *wf = wavtag_open("song.wav");
if (!wf) {
    /* wavtag_errno() gives a reason */
}

const char *artist = wavtag_get(wf, WAVTAG_ARTIST);
const char *title  = wavtag_get(wf, WAVTAG_TITLE);

wavtag_set(wf, WAVTAG_COMMENT, "Remastered 2024");
wavtag_save(wf, "song.wav");

wavtag_close(wf);
```

`wavtag_open` parses the RIFF/WAVE structure and locates the `LIST/INFO`
chunk if one exists (a file with no existing tags opens fine — reads just
return NULL). `wavtag_get` and `wavtag_set` take one of the `WAVTAG_*`
field constants (`WAVTAG_ARTIST`, `WAVTAG_TITLE`, `WAVTAG_COMMENT`,
`WAVTAG_GENRE`, `WAVTAG_DATE`, and a few others mapping to the standard
INFO subchunk IDs). `wavtag_save` writes the file back out, rebuilding the
`LIST/INFO` chunk from whatever tags are currently set and copying the
`data` chunk through unchanged.

## Byte order

WAV is a RIFF-based format and is little-endian on disk regardless of the
host platform. wavtag handles that conversion internally — every chunk
size and INFO field length is read and written through
`wavtag_le32_to_host`/`wavtag_host_to_le32` helpers rather than assuming
the host matches the file. This means wavtag works correctly on
big-endian platforms as well as the far more common little-endian ones;
if you're embedding wavtag in something running on unusual hardware, you
don't need to do any byte-swapping yourself.
