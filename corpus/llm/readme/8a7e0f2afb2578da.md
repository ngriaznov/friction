# soilwatch

Battery-powered soil moisture logger for Arduino. Takes a reading at a fixed interval, timestamps it from a real-time clock, appends it to a CSV file on an SD card, and goes back to sleep. Optionally transmits each reading over a low-power radio link so you can watch a bed from indoors.

Runs about four months on three AA cells at the default 30-minute sampling interval.

## Hardware

- An ATmega328P board. A 3.3V/8MHz Pro Mini is what this was developed on; a Uno works but will not sleep nearly as well because of the onboard regulator and USB chip.
- **Capacitive** soil moisture probe. Not resistive. Resistive probes corrode within weeks of continuous burial.
- DS3231 RTC module. The cheap DS1307 drifts badly outdoors as temperature swings.
- SD card breakout, SPI.
- Optional: RFM69HCW radio module (433 or 915 MHz, match your region).

## Wiring

Probe signal to A0, probe VCC to D4 rather than the rail — the firmware powers the probe only during a reading, which saves roughly 5mA of continuous draw and slows probe degradation. Probe ground to GND.

RTC on I2C: SDA to A4, SCL to A5. Its SQW pin goes to D2, the interrupt that wakes the board.

SD breakout on the SPI bus: MOSI D11, MISO D12, SCK D13, and CS on D10.

If you fit the radio, it shares the SPI bus. Its CS goes to D8 and its DIO0 interrupt to D3. Give it its own 100µF bulk capacitor close to the module; transmit bursts will otherwise brown out the SD card.

## Flashing

Open `soilwatch.ino` in the Arduino IDE. Install these libraries through the Library Manager: `RTClib`, `SdFat`, `LowPower`, and `RadioHead` if you are using the radio. Select your board and port, then upload. On a Pro Mini you will need an FTDI adapter and should press reset as the upload begins.

## Configuration

Everything tunable lives in the block of `#define`s at the top of `config.h`:

| Constant | Default | Notes |
|---|---|---|
| `SAMPLE_MINUTES` | `30` | Interval between readings. |
| `CAL_DRY` | `620` | ADC reading with the probe in open air. |
| `CAL_WET` | `290` | ADC reading with the probe in a glass of water. |
| `RADIO_ENABLED` | `0` | Set to `1` to compile in the radio path. |
| `NODE_ID` | `1` | Appears in the CSV and in radio packets. |

Calibrate before burying anything. Flash the sketch with `SERIAL_DEBUG` set to `1`, open the serial monitor, and note the raw values in air and in water. Put those in `CAL_DRY` and `CAL_WET`, set `SERIAL_DEBUG` back to `0`, and reflash. Percentages are linearly interpolated between the two, clamped to 0–100.

## Reading the log

The card gets one file per month, named `YYYY-MM.CSV`:

```
timestamp,node,raw,percent,vbat
2026-04-12T08:00:00,1,431,57.2,4.41
2026-04-12T08:30:00,1,438,55.4,4.41
```

`raw` is the uncalibrated ADC value, kept so you can re-derive percentages if you recalibrate later. `vbat` is battery voltage; when it drops under 3.4V the readings start reading dry and it's time for new cells.
