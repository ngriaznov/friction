**Subject:** Sieve — contributor call notes, March

Hi all,

Notes from Tuesday's call. Recording is in the usual place; this covers the parts that need follow-up.

**Merged since February**

Thirty-one PRs landed. The ones worth knowing about:

- `#812` — streaming parser no longer buffers the whole payload. Memory use on the 500MB fixture dropped from 1.9GB to 140MB. Thanks to @rmoreau for three rounds of review patience.
- `#824`, `#827` — Windows path handling. Between them these close six open issues, some of them over two years old.
- `#831` — the docs site now builds reproducibly. If you've been unable to preview docs locally, pull and try again.
- `#836` — dropped Python 3.8. It went EOL in October and was blocking the typing cleanup.

Full list in the milestone.

**Proposed breaking change: plugin API**

The bulk of the call. @jkessler's proposal (RFC in `#798`) replaces the current `register()` hook with an explicit `Plugin` protocol carrying `setup()` / `teardown()`. Motivation is that plugins currently have no way to release resources, and we've had three separate bug reports that all trace back to that.

Rough consensus on the call was that the change is right. Disagreement was about migration. Two positions:

1. Ship both APIs in 2.0 with `register()` deprecated, remove in 3.0.
2. Break cleanly in 2.0 with a codemod.

We counted 41 plugins on the registry. @sfarrell volunteered to check how many use `register()` in a way the codemod couldn't handle and will report back before the next call.

**Open questions needing maintainer input**

- Issue `#805` — should config file discovery walk up past a `.git` boundary? Two maintainers have opposite instincts. Please weigh in on the thread rather than the call, so it's written down.
- Issue `#819` — nobody has claimed the Homebrew formula since @dpell stepped back in November. If you're a Homebrew user, this is a small, self-contained job.
- We still need a decision on whether the 2.0 changelog gets a hand-written migration guide or generated release notes. Volunteer needed either way.
