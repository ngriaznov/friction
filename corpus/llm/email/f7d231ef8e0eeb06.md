Subject: Emberfall Dev Update — Dash Mechanic, Wishlist Milestone, and What's Next

Hey everyone,

Been a little while since the last update, so there's a decent amount to cover this month. Grab a coffee.

**The dash mechanic is in**

The big feature this month is a proper dash move for the player character. This has been on the design doc since basically day one, but I kept pushing it back because I was worried about scope creep — a dash sounds simple until you start thinking about how it interacts with every other system in the game. And that worry was justified, honestly. It touched more than I expected: collision detection needed a special case so you don't dash through thin platform edges, the camera needed a quick punch-in and lookahead adjustment so dashing doesn't feel disorienting, and I had to rebalance three existing levels because suddenly players could skip sections that were designed around normal movement speed.

That said, it's in now, and it feels good. There's a short cooldown, a small screen-shake and particle trail on activation, and — this took way longer than it should have — a dedicated sound effect that doesn't get annoying on the fortieth use in a row. I went through six different sound variations before landing on one that felt punchy without being grating. If you want to see it in motion, I posted a 15-second clip on the devlog page linked at the bottom of this email.

Next up on the movement front is a wall-cling mechanic, which the dash work has actually made easier since a lot of the collision groundwork is now shared between the two.

**Wishlist milestone: 10,000**

Emberfall crossed 10,000 Steam wishlists this week, which is a number I honestly wasn't expecting to hit before the demo even exists. I want to say clearly: that milestone is almost entirely because of people in this list sharing clips, posting in communities, and just talking about the game to people who might be interested. I don't have a marketing budget in any meaningful sense — this has been word of mouth from the start, and it's humbling every time the number ticks up in a way I didn't personally cause.

For context, I've heard that somewhere in the 7,000–10,000 range is roughly when a lot of Steam's internal discovery algorithms start giving a game meaningfully more visibility, so this milestone might matter more than just being a nice round number. We'll see.

**Demo timeline**

This is the part everyone actually wants to know about, so let me be straight with you: I'm targeting a public demo build in roughly ten to twelve weeks, which would put it in the window for one of the big Steam festival events, though I don't want to commit to a specific one until I have a build I'm confident submitting. That timeline assumes the wall-cling mechanic goes as smoothly as the dash did (no guarantees there) and that level 4, which is currently about 60% blocked out, doesn't run into the kind of pacing problems level 2 gave me back in the spring.

I'd rather give you a slightly conservative estimate and beat it than promise something in six weeks and quietly slip it three times — you've all seen enough indie dev postmortems to know how that story usually goes.

**Small stuff**

- Fixed a nasty bug where enemy pathfinding would break near diagonal platform edges — this had been bothering me since basically forever and I finally traced it to a rounding error in the pathfinding grid.
- Redid the health/stamina UI in the corner of the screen; old version was functional but ugly, new one actually matches the game's art direction now.
- Added controller support for the dash (was keyboard-only for the first week, oops).
- Swapped the tileset for the underground caverns section — the old one was a placeholder I'd been meaning to replace since basically the start of the project, and it finally looks like it belongs in the same game as everything else.
- Started experimenting with a very early version of a parry mechanic for the melee-focused enemies. Not committing to anything yet, just prototyping in a separate branch to see if it's fun before I decide whether it's worth the scope.

**A quick note on funding and sustainability**

A few people have asked whether Emberfall is my full-time thing right now. Short answer: not quite yet, but getting closer. I'm still doing part-time contract work on the side to cover the basics, but the freelance hours have been shrinking steadily as pre-release wishlist momentum builds, and I'm hoping to go fully full-time on the game once the demo is out and I have a clearer read on how the festival showing goes. I mention this mostly because it explains some of the slower stretches between updates — those are almost always contract-work crunches, not lost motivation on the game itself.

As always, thank you for reading this far and for being along for the ride. If you want to chat directly, I'm active most days in the Discord linked below, and I try to respond to every reply to these emails even if it takes me a few days.

Next update in about a month, probably with wall-cling footage if things go well.
