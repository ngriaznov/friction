# Quillfeather Keyboard Shortcuts

Quillfeather is fully operable from the keyboard. This page lists every default shortcut, grouped by category. Shortcuts can be remapped in `~/.config/quillfeather/keymap.toml`; the bindings below are the defaults shipped with the editor.

Notation: `C-` means Ctrl, `M-` means Alt/Meta, and a space between keys (e.g. `C-x C-s`) means press them in sequence, not simultaneously.

## Navigation

| Shortcut | Action |
|---|---|
| `C-n` / `C-p` | Move cursor down / up one line |
| `C-f` / `C-b` | Move cursor forward / back one character |
| `M-f` / `M-b` | Move forward / back one word |
| `C-a` / `C-e` | Move to start / end of line |
| `M-<` / `M->` | Move to start / end of file |
| `C-v` / `M-v` | Scroll down / up one page |
| `M-g g` | Go to line number (prompts for a number) |
| `C-x C-o` | Jump to matching bracket |
| `M-.` | Jump to definition (requires a language server for the buffer's file type) |
| `M-,` | Jump back from a definition jump |

## Editing

| Shortcut | Action |
|---|---|
| `C-d` | Delete character under cursor |
| `M-d` | Delete word forward |
| `C-k` | Kill (cut) to end of line |
| `C-y` | Yank (paste) most recently killed text |
| `C-_` or `C-/` | Undo |
| `C-x u` | Redo |
| `M-u` / `M-l` | Uppercase / lowercase word forward |
| `C-x C-i` | Auto-indent current line |
| `Tab` | Indent selection (or insert indent at cursor if no selection) |
| `C-x r t` | Insert current date/time at cursor |

## Search

| Shortcut | Action |
|---|---|
| `C-s` | Incremental search forward |
| `C-r` | Incremental search backward |
| `M-%` | Search and replace (prompts for both terms) |
| `C-M-s` | Search with regular expression |
| `M-s o` | List all matches in current buffer in a results pane |
| `C-x g` | Grep across all files in the current project directory |
| `Escape` | Exit search / cancel current prompt |

## Window management

| Shortcut | Action |
|---|---|
| `C-x 2` | Split window horizontally |
| `C-x 3` | Split window vertically |
| `C-x o` | Move focus to next window |
| `C-x 0` | Close current window |
| `C-x 1` | Close all windows except the current one |
| `C-x b` | Switch to another open buffer |
| `C-x C-b` | List all open buffers |
| `C-x k` | Kill (close) current buffer |
| `C-x C-f` | Open (find) a file |
| `C-x C-s` | Save current buffer |
| `C-x C-w` | Save current buffer under a new name |
| `C-x C-c` | Quit Quillfeather (prompts to save any unsaved buffers) |

A quick note on remapping: entries in `keymap.toml` follow the same `C-`/`M-` notation used above, so `C-x C-s = "save-buffer"` in that file corresponds directly to the table entry here. Running `quillfeather --print-keymap` dumps your active, fully-resolved bindings (defaults plus any overrides) to stdout, which is the most reliable way to check what a given key sequence actually does on your system after customizing it.
