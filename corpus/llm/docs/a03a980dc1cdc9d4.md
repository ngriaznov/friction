# Straightline CLI reference

`straightline` reads source files, reformats them, and writes them back in place. Every flag below can also be set in `straightline.toml` at the project root; command-line flags win when both are present.

```
straightline [OPTIONS] [PATH...]
```

If no `PATH` is given, Straightline formats the current directory recursively.

## `--line-width <N>`

Sets the column at which Straightline prefers to break a line. Default is `100`.

This is a soft target, not a hard cap. Straightline will exceed it rather than break constructs it cannot break safely — long string literals, single-token identifiers, and URLs inside comments are all left alone. Setting `--line-width 0` disables width-driven wrapping entirely; expressions are then broken only where the source already contains a newline the formatter considers meaningful.

Accepted range is `0` and `40`–`400`. Values outside that range exit with status `2`.

```
straightline --line-width 80 src/
```

## `--indent-style <style>`

One of `spaces` (default) or `tabs`.

With `spaces`, the width of one indent level is taken from `--indent-width`, which defaults to `4`. With `tabs`, one level is a single tab character and `--indent-width` is ignored for output, though it is still used when Straightline needs to guess how wide a tab renders for alignment purposes.

Continuation lines inside a wrapped expression always use one additional level, never a partial one. Straightline does not do column-alignment of arguments, so mixing tabs and spaces on a single line never happens in output.

## Ignore-file syntax

Straightline reads `.straightlineignore` from the directory it starts in and from every directory it descends into. Patterns are matched against the path relative to the file that declares them.

- Blank lines and lines beginning with `#` are ignored.
- `build/` matches a directory and everything under it.
- `*.gen.ts` matches by glob within a single path segment.
- `**/vendor` matches at any depth.
- A leading `/` anchors the pattern to the declaring directory: `/tmp` matches only the top-level `tmp`.
- A leading `!` re-includes a path that an earlier pattern excluded. Order matters; the last matching pattern decides.

An example:

```
# generated protobuf output
**/*.pb.go
vendor/
!vendor/internal/hand-edited.go
```

Straightline also honours `.gitignore` unless you pass `--no-gitignore`. Files ignored by git but listed explicitly on the command line are still formatted — an explicit path is always treated as an instruction.

## Check-only mode for CI

Pass `--check` to make Straightline report rather than rewrite:

```
straightline --check .
```

Exit codes:

| Code | Meaning |
| --- | --- |
| `0` | Everything is already formatted |
| `1` | One or more files would change |
| `2` | Invalid configuration or unreadable input |

Nothing is written to disk in this mode. The names of files that would change go to stdout, one per line, which makes the output easy to feed into a follow-up step.

Add `--diff` to print a unified diff of the proposed changes instead of just filenames — useful when a contributor needs to see what the pipeline objected to without cloning and re-running locally. Combine with `--quiet` to suppress the summary line and keep the log tight.
