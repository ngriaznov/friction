# Getting Started with dedupe-shots

`dedupe-shots` is a command-line tool that scans a photo library for duplicate and near-duplicate images using perceptual hashing, rather than exact byte comparison. This means it can catch resized copies, re-exported JPEGs, and burst-mode near-twins that a simple checksum would miss.

## Installation

The easiest way to install is via pip:

```
pip install dedupe-shots
```

This installs the `dedupe-shots` command along with its dependencies (Pillow for image decoding and a small perceptual-hashing library). Python 3.8 or later is required.

If you'd rather not touch your system Python, a standalone binary is available for macOS and Linux from the releases page. Download the archive for your platform, extract it, and place the `dedupe-shots` binary somewhere on your `PATH`.

Verify the install with:

```
dedupe-shots --version
```

## Running a basic scan

Point the tool at a directory and let it index your photos:

```
dedupe-shots scan ~/Pictures
```

By default this walks the directory recursively, computes a perceptual hash (pHash) for every image it finds, and groups images whose hashes are within a configurable Hamming distance of each other. The scan does not touch any files — it only builds an index and reports groups of likely duplicates.

For large libraries, the first scan can take a while since every image needs to be decoded and hashed. Subsequent scans are much faster because `dedupe-shots` caches hashes in a `.dedupe-shots-cache` file inside the scanned directory, keyed by file path and modification time. If you move the library, you can delete this cache file safely; it will simply be rebuilt.

You can tighten or loosen how aggressively images are matched with `--threshold`:

```
dedupe-shots scan ~/Pictures --threshold 6
```

Lower values require closer visual similarity before two images are considered duplicates. The default of 8 works well for exact re-encodes and minor crops; if you're seeing false positives among visually similar but distinct photos (e.g. several frames from the same burst), try lowering it to 4 or 5.

## Previewing matches before deleting

`dedupe-shots` never deletes anything on its own during a scan. To review what it found, run:

```
dedupe-shots review
```

This opens an interactive list of duplicate groups in your terminal, showing file paths, dimensions, file sizes, and a similarity score for each pair. Use the arrow keys to move between groups and press `d` to mark individual files (never entire groups) for deletion. Nothing is removed from disk until you confirm.

If you prefer a non-interactive summary, `--report` writes the same information to a file instead:

```
dedupe-shots scan ~/Pictures --report duplicates.txt
```

You can inspect this file at your leisure, cross off files you want to keep, and feed the survivors back into a targeted delete pass.

## Deleting duplicates

Once you're satisfied with what will be removed, run:

```
dedupe-shots clean --keep-largest
```

`--keep-largest` retains the highest-resolution file in each duplicate group and removes the rest. Other keep strategies include `--keep-oldest` and `--keep-newest`, based on file modification time. Every deletion pass writes a log of removed files to `.dedupe-shots-trash.log` in case you need to recover a mistake — deleted files are moved to your system trash by default, not permanently erased, unless you pass `--permanent`.

That's the core workflow: scan, review, clean. For batch processing of multiple libraries or scripting the scan into a nightly job, see the reference page on flags and exit codes.
