# Quillfeather Keyboard Shortcuts

Quillfeather is a modal, terminal-based text editor. Shortcuts below assume the default keymap in **normal mode** unless otherwise noted. Chords are written with `+` for simultaneous keys and a space for sequential presses (press one, release, then press the next).

## Navigation

| Shortcut | Action |
|---|---|
| `h` `j` `k` `l` | Move left, down, up, right |
| `w` / `b` | Jump forward / backward one word |
| `0` / `$` | Jump to start / end of line |
| `gg` / `G` | Jump to top / bottom of file |
| `Ctrl+d` / `Ctrl+u` | Scroll down / up half a page |
| `%` | Jump to matching bracket, paren, or brace |
| `Ctrl+o` / `Ctrl+i` | Step backward / forward through jump history |
| `zz` | Center the current line in the viewport |

## Editing

| Shortcut | Action |
|---|---|
| `i` / `a` | Enter insert mode before / after the cursor |
| `o` / `O` | Open a new line below / above and enter insert mode |
| `x` | Delete the character under the cursor |
| `dd` | Delete the current line |
| `yy` | Yank (copy) the current line |
| `p` / `P` | Paste after / before the cursor |
| `u` / `Ctrl+r` | Undo / redo |
| `>>` / `<<` | Indent / outdent the current line |
| `.` | Repeat the last change |

## Search

| Shortcut | Action |
|---|---|
| `/pattern` | Search forward for `pattern` |
| `?pattern` | Search backward for `pattern` |
| `n` / `N` | Repeat last search forward / backward |
| `*` | Search forward for the word under the cursor |
| `Ctrl+p` | Open the fuzzy file finder |
| `Ctrl+Shift+f` | Open project-wide grep search |
| `:%s/old/new/g` | Replace all occurrences of `old` with `new` on every line |

## Window Management

| Shortcut | Action |
|---|---|
| `Ctrl+w s` | Split the current pane horizontally |
| `Ctrl+w v` | Split the current pane vertically |
| `Ctrl+w h/j/k/l` | Move focus to the pane in that direction |
| `Ctrl+w q` | Close the current pane |
| `Ctrl+w =` | Resize all panes to equal size |
| `gt` / `gT` | Switch to the next / previous tab |
| `:tabnew` | Open a new tab |
| `Ctrl+w o` | Close every pane except the current one |

## A Note on Remapping

All of the bindings above live in `~/.config/quillfeather/keymap.toml` and can be freely overridden. Running `:keymap show` from command mode prints the active bindings for the current buffer, which is useful for spotting a conflict after a plugin adds its own chord. If a shortcut listed here doesn't respond, check that file first — it's the most common cause of drift between this reference and what's actually bound on your machine.
