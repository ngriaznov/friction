# Getting Started with dedupe-shots

`dedupe-shots` is a command-line tool that finds duplicate and near-duplicate photos across your local photo library. Instead of comparing files byte-for-byte, it uses perceptual hashing, which means it can catch copies that have been resized, re-compressed, or re-exported at a different quality level but still look the same to the eye.

## Installation

`dedupe-shots` is distributed as a single static binary with no external dependencies. On macOS and Linux, the quickest path is the install script:

```
curl -fsSL https://get.dedupe-shots.dev/install.sh | sh
```

This drops the `dedupe-shots` binary into `~/.local/bin`. Make sure that directory is on your `PATH`, then confirm the install:

```
dedupe-shots --version
```

If you'd rather not pipe a script into your shell, download the appropriate archive from the releases page and place the binary somewhere on your `PATH` yourself. Windows users can grab the `.exe` from the same page; there's no installer, just an executable.

## Running a basic scan

Point `dedupe-shots` at one or more directories with the `scan` subcommand:

```
dedupe-shots scan ~/Pictures
```

This walks the directory recursively, computes a perceptual hash for every image it finds, and groups images whose hashes are within a configurable distance of each other. By default it uses a difference hash (dHash) with a similarity threshold tuned to catch resized and re-encoded duplicates while leaving genuinely different photos alone. You can scan multiple locations in one pass:

```
dedupe-shots scan ~/Pictures ~/Downloads/camera-import
```

A scan against a large library can take a few minutes the first time, since every file has to be hashed. Results are cached in a local index (`~/.cache/dedupe-shots/`), so subsequent scans of the same directories only hash new or changed files.

## Previewing matches before deleting anything

`dedupe-shots` never deletes files during a scan. Once a scan finishes, it writes a report you can review:

```
dedupe-shots scan ~/Pictures --report duplicates.html
```

Open `duplicates.html` in a browser to see each group of matched photos side by side, along with file size, resolution, and modification date, so you can tell at a glance which copy in a group is the original and which are the copies. For a quicker terminal-only look, use `--report -` to print groups as plain text instead.

When you're ready to act on a group, use `review`, which walks through each duplicate set interactively and lets you choose which file in the group to keep:

```
dedupe-shots review duplicates.html
```

Nothing is removed until you confirm a choice for each group, and every deletion is logged to `~/.cache/dedupe-shots/deleted.log` so you can see exactly what was removed and when. If you want to be extra cautious, pass `--trash` instead of `--delete` during review to send removed files to your system trash rather than deleting them outright.

That's enough to get a first library cleaned up. From here, check `dedupe-shots scan --help` for tuning the hash algorithm and similarity threshold to your own tolerance for near-duplicates.
