# Quillfeather Keyboard Shortcuts

Every shortcut below works in the default keymap. If you have set `keymap = "vim"` or `keymap = "emacs"` in your config, only the window management bindings carry over unchanged; the rest follow the emulated editor's conventions.

Notation: `C-` means Control, `M-` means Alt (or Option on macOS), and `S-` means Shift. `C-x C-s` means press Control-x, release, then press Control-s.

## Navigation

| Shortcut | Action |
| --- | --- |
| `C-a` / `C-e` | Jump to start / end of the current line |
| `M-Left` / `M-Right` | Move one word backward / forward |
| `C-Up` / `C-Down` | Move to previous / next blank line (paragraph jump) |
| `C-g` | Prompt for a line number and go there |
| `C-Home` / `C-End` | Jump to start / end of the buffer |
| `M-.` | Jump back to the last edit position |
| `M-,` | Jump forward again after `M-.` |

`M-.` keeps a ring of the last sixteen edit positions, so pressing it repeatedly walks backward through your editing history rather than toggling between two spots.

## Editing

| Shortcut | Action |
| --- | --- |
| `C-k` | Delete from cursor to end of line |
| `C-u` | Delete from cursor to start of line |
| `C-w` | Delete the word before the cursor |
| `C-d` | Duplicate the current line below |
| `M-Up` / `M-Down` | Move the current line up / down |
| `C-/` | Toggle comment on the line or selection |
| `C-z` / `C-S-z` | Undo / redo |
| `Tab` / `S-Tab` | Indent / dedent the selection |

Deletions made with `C-k`, `C-u`, and `C-w` are appended to the kill ring, not the system clipboard. Paste them back with `C-y`, and cycle through older entries with `M-y` immediately afterward.

## Search

| Shortcut | Action |
| --- | --- |
| `C-s` | Incremental search forward |
| `C-r` | Incremental search backward |
| `C-s` (during search) | Jump to the next match |
| `Esc` | Accept the current position and exit search |
| `C-S-f` | Search across all files in the project root |
| `M-%` | Query replace, confirming each match |
| `C-M-%` | Query replace using a regular expression |

During a query replace, press `y` to replace, `n` to skip, `!` to replace all remaining without asking, and `q` to stop.

## Window management

| Shortcut | Action |
| --- | --- |
| `C-x 2` | Split the window horizontally |
| `C-x 3` | Split the window vertically |
| `C-x 0` | Close the focused pane |
| `C-x 1` | Close every pane except the focused one |
| `C-x o` | Cycle focus to the next pane |
| `C-x b` | Switch buffers by name |
| `C-x C-b` | List open buffers |
| `C-x k` | Kill the current buffer |

Panes remember their scroll position when focus moves away, so `C-x o` is safe to use while comparing two regions of the same file.

## Customizing bindings

Add a `[keys]` table to `~/.config/quillfeather/config.toml` to rebind anything listed above. Keys are shortcut strings, values are command names:

```toml
[keys]
"C-p" = "buffer.previous"
"C-n" = "buffer.next"
```

Run `quillfeather --list-commands` for the full command vocabulary. Unrecognized command names are reported at startup and the binding is skipped; the rest of the config still loads.
