# Thistle Configuration Reference

Thistle reads a single configuration file, `thistle.toml`, from the root of your site directory. This page documents the supported top-level keys, how per-page front matter can override them, and provides two complete example configurations.

## Top-Level Keys

### `title`

A string giving the site's name. It's used in the default `<title>` tag template and is available to themes as `{{ site.title }}`. There is no default — Thistle will refuse to build without one.

```toml
title = "Cedar & Stone"
```

### `base_url`

The absolute URL where the site will be deployed, without a trailing slash. Thistle uses this to generate absolute links in the RSS feed, canonical tags, and sitemap. During local preview (`thistle serve`), this value is ignored in favor of `http://localhost:4000`.

```toml
base_url = "https://cedarandstone.example.com"
```

### `theme`

The name of an installed theme directory under `themes/`. Thistle ships with two built-in themes, `paper` and `slate`. If omitted, Thistle falls back to `paper`.

```toml
theme = "slate"
```

### `output_dir`

The directory, relative to the project root, where Thistle writes the built site. Defaults to `public/` if not set. Thistle empties this directory before every build, so avoid pointing it at anything you don't want wiped.

```toml
output_dir = "dist"
```

## Front Matter Overrides

Any page in `content/` can override `title` and `theme` for that single page by declaring front matter at the top of its Markdown file, delimited by `+++` lines. `base_url` and `output_dir` are build-wide settings and cannot be overridden per page — Thistle will raise a build error if it finds either key in front matter.

```markdown
+++
title = "About the Studio"
theme = "paper"
+++

# About

We've been building furniture since 2011...
```

When a page omits front matter entirely, it inherits `title` and `theme` from `thistle.toml`. The overridden `title` also feeds into the page's `<title>` tag and any breadcrumb templates the theme defines, but it does not change the site-wide `title` used elsewhere, such as in the RSS feed's channel name.

## Example: Minimal Config

A blog with no customization beyond the required `title` and `base_url`:

```toml
title = "Notes from the Shop"
base_url = "https://notesfromtheshop.example.com"
```

This build uses the `paper` theme and writes output to `public/`.

## Example: Full Config

A photography portfolio with a custom theme and output directory:

```toml
title = "Arden Vance Photography"
base_url = "https://ardenvance.example.com"
theme = "slate"
output_dir = "site-build"
```

Combined with a per-page override, a single portfolio page might look like:

```markdown
+++
title = "Iceland, Winter 2024"
+++

![Glacier at dusk](/images/iceland-01.jpg)

Three weeks chasing light across the southern coast.
```

That page's browser tab will read "Iceland, Winter 2024," while every other page on the site still uses the site-wide "Arden Vance Photography" title. The `slate` theme and `site-build` output directory apply to the whole build regardless of any front matter, since neither key is eligible for per-page override.

## A Note on Validation

Thistle validates `thistle.toml` before every build and will exit with a nonzero status if `title` or `base_url` is missing, or if `theme` references a directory that doesn't exist under `themes/`. Front matter validation happens per file, so a typo in one page's front matter won't block the rest of the site from building — Thistle logs a warning and falls back to the site-wide values for that page instead.
