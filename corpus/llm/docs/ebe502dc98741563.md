# Getting started with dedupe-shots

`dedupe-shots` finds duplicate photos in a local library by comparing what the images *look* like rather than comparing bytes. That means a JPEG you re-exported at 80% quality, or a copy your phone downscaled on the way into a chat app, still gets matched against the original. Nothing is deleted unless you ask for it.

## Install

The tool ships as a single static binary. Grab the release for your platform and put it somewhere on your `PATH`:

```
curl -LO https://get.dedupe-shots.dev/v2.1/dedupe-shots-macos-arm64
chmod +x dedupe-shots-macos-arm64
mv dedupe-shots-macos-arm64 /usr/local/bin/dedupe-shots
```

Homebrew and a Debian package are also available:

```
brew install dedupe-shots
```

Check that it works:

```
dedupe-shots --version
```

There is no daemon and no configuration file to create. State lives in a single SQLite database at `~/.cache/dedupe-shots/index.db`, which you can delete at any time to start over.

## Your first scan

Point the tool at a directory. It walks the tree, decodes every image it recognizes, and stores a perceptual hash for each one.

```
dedupe-shots scan ~/Pictures
```

The first run over a large library takes a while — expect roughly a minute per 10,000 photos on a modern laptop, longer if your files live on a spinning disk or a network share. Progress is printed to stderr, so you can redirect stdout without losing it.

Subsequent scans are incremental. Files are keyed by path, size, and modification time, so re-running `scan` on the same directory only hashes what changed.

Supported formats: JPEG, PNG, HEIC, TIFF, WebP, and the common raw formats (CR2, NEF, ARW, DNG). Videos are ignored.

## Reviewing matches before you delete

This is the important part. `scan` never removes anything — it only builds the index. To see what it found, run:

```
dedupe-shots review ~/Pictures
```

You get one group per set of near-identical images, with the file sizes and dimensions listed so you can tell which copy is the good one:

```
Group 1  (distance 0–2)
  * 4032x3024  3.8 MB  2023/06/IMG_4471.HEIC
    1024x768   210 KB  Downloads/IMG_4471.jpg
    1024x768   198 KB  Desktop/to-send/IMG_4471 (1).jpg
```

The `*` marks the file the tool would keep by default: highest resolution, then largest file, then oldest modification time. Distance is the Hamming distance between hashes — 0 means the hashes are identical, and anything up to 8 is usually the same picture.

If the grouping feels too loose or too strict, adjust the threshold:

```
dedupe-shots review ~/Pictures --threshold 4
```

Lower is stricter. Burst-mode sequences and bracketed exposures are the usual reason to tighten it.

When the groups look right, write them to a file, edit it by hand if you want, and act on that:

```
dedupe-shots review ~/Pictures --output plan.txt
dedupe-shots apply plan.txt --trash
```

`--trash` moves files to your system trash instead of unlinking them. Use it until you trust the results.
