**Subject: Finally killed the dead zones after going mesh — here's what actually worked**

Posting this because I searched half this forum before I fixed it and figured I'd close the loop for the next person.

Two-story house, roughly 2,400 sq ft, brick exterior on one side which I now believe was half the problem. Put in a three-node mesh system replacing a single router, expecting the dead zone in the back bedroom and the detached-feeling garage to just go away. They didn't, not at first.

**Attempt 1: nodes in a line.** I put node 1 where the old router lived (front hall, main floor), node 2 upstairs at the top of the stairs, node 3 in the back bedroom that had been the worst dead zone. Signal in the back bedroom got better, but the garage got *worse*, and I started seeing weird slowdowns in the kitchen that hadn't been a problem before. Checked the app, and node 3 was backhauling through node 2, which was backhauling through node 1, and the kitchen sits almost equidistant between all three, apparently just far enough from each to be picking the wrong one intermittently.

**Attempt 2: triangulating instead of lining up.** Moved node 2 off the stairs and into a central upstairs hallway instead, and moved node 3 from the back bedroom to a hallway closet just outside it, closer to line-of-sight with node 2 rather than buried in the room itself with a wall between it and everything. This is the change that mattered most — a mesh node crammed into the room with the worst signal is usually the wrong instinct, because it also has the worst signal to its backhaul neighbor. It needs to be somewhere with a decent path to another node, even if that means it's not literally standing in the dead zone.

**Backhaul band issue.** Even after repositioning, I was getting occasional drops. Turned out the system was defaulting to using the same 5GHz band for backhaul and for client devices when nodes were close enough, which meant every phone connecting to node 2 competed with node 2's link back to node 1 for the same airtime. Forcing a dedicated backhaul band in the app settings (mine has an option to prioritize a specific band for inter-node traffic) fixed the intermittent drops entirely.

**What finally worked, in order:** central hallway placement over in-room placement, dedicated backhaul band, and — smaller thing but worth mentioning — moving node 1 a foot away from the cordless phone base station, which I hadn't considered a source of interference until I stumbled on it by accident while vacuuming.

Garage is still weak, but that's a detached structure with no line of sight, so I'm treating that as a wired access point problem for another weekend, not a mesh placement problem. Everything inside the house is now solid, phone doesn't drop connection walking between rooms anymore.

If you're mid-troubleshooting: try the hallway/line-of-sight placement before you buy a fourth node.
